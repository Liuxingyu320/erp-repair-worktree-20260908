# ERP-NEW_2 阶段 1 复核与检查点

> 日期：2026-08-03
> 状态：阶段 1 滚动盘点已同步到当前工作树；24 条目标映射已落账，业务契约仍未冻结

## 1. 已完成范围

- 173 个旧前端 Vue 页面/组件全部进入迁移矩阵：桌面 137 个、移动网页 36 个。
- 48 个直接路由/菜单页面、68 个组件级条目、57 个未映射入口候选均保留，不因不可见而自动下线。
- 526 个前端 API 调用和 635 个后端 Controller/网关端点进入契约基线。
- 523 个前端调用获得方法与规范化路径的精确候选匹配；3 个动态分派已人工展开说明。
- 240 个权限标识按前端、后端和 SQL 证据交叉核验。
- 116 个页面/组件关联到前端 API，133 个通过严格源码路径或非泛化组件名关联到自动化测试证据。
- 873 个旧能力与新目标输入证据文件记录大小与 SHA-256，覆盖新前端 API、路由、壳层、设计系统、页面、领域、平台、Provider 与测试夹具；连续两次生成结果一致。
- 24 条已有明确新代码证据的旧能力写入“重设计 / 部分实现”目标映射；其余 149 条继续保持待确认。
- 旧前端测试和新前端目标测试使用独立列保存，不因回填目标证据而覆盖旧回归证据。
- 21st.dev、React Bits、UI Prompt Library、Magic UI、Motion Primitives、Uiverse 和 MotionSites 已纳入前端设计参考与原创适配约束。

## 3. 尚未完成且本阶段不应猜测的事项

1. 未连接 ERP-NEW_2 专属数据库，因此没有验证动态菜单运行态和角色实际授权。
2. 未启动后端；仓库当前没有已提交的 OpenAPI 文件，因此精确路径匹配不是运行时契约测试，也不能替代版本化 OpenAPI。
3. 未确认 13 个后端单边权限和 12 个 SQL 单边权限的业务归属。
4. 未确认任何页面的下线、合并或不兼容 API 修改。
5. 未创建或删除旧前端；新前端 `erp-ui-next/` 已开始并形成 24 条部分实现映射，但不等于全领域迁移完成。
6. 按用户最新决定，本阶段未使用 Docker，也未启动 MySQL、Redis、Nacos 或应用服务。

## 4. 下一检查点建议

后续每个前端领域切片都必须同步更新 `target-mapping-overrides.csv`：

1. 新页面只有同时提供目标路由、组件、测试、检查点和真实实施边界，才可写入“部分实现 / 已实现”；
2. 已有 24 条“部分实现”必须在真实契约、异常动作和领域验收完成后才能升级为“已实现”；
3. 继续核验 149 条未决目标处置和权限单边引用；
4. 任何“合并 / 下线”覆盖项必须先有明确确认，否则生成器拒绝；
5. 继续保持无 Docker、无服务、无数据库连接，直到运行环境重新获得明确授权。

删除旧前端、下线能力、合并业务、推送分支和连接任何数据库仍不在本检查点授权范围内。
