## 1. 本检查点交付

本轮在全新目录 `erp-ui-next/` 内补齐以下平台能力，并接入调拨原型：

- 用户与组织双重隔离的本地视图偏好，包括筛选、表格密度和列可见性；
- 当前筛选结果的本地 CSV 导出，包括 UTF-8 BOM、公式注入防护和安全文件名；
- 大数据量导出门禁：超过同步阈值时不在浏览器伪造全量导出，而是要求后端异步任务继承权限与数据范围；
- 文件任务状态机，以及图片/PDF 的扩展名、MIME、大小、数量和空文件校验；
- 差异收货的本地证据选择、预览、失败重试、移除和生命周期清理；
- 注册式任务深链，只接受预定义目标和稳定业务标识，并在跳转前再次校验功能开关与权限；
- 统一错误呈现，包括字段错误、追踪编号、可重试动作和重新登录动作；
- 桌面工作台、移动待办与移动差异收货流程的集成回归。

界面继续遵循 `docs/ERP-NEW_2-前端设计参考与使用约束.md`：参考 21st.dev、React Bits、UI Prompt Library、Magic UI、Motion Primitives、Uiverse 与 MotionSites 的设计语言，但所有实现都转换为本项目的 Vue 3、设计令牌、可访问性和低动效约束，不直接引入来源站点的 React、Tailwind 或运行时代码。

## 2. 关键安全边界

- 偏好键固定使用 `erp-new-2:preferences:v1` 前缀，并按用户和组织分区；损坏或版本不兼容的数据默认丢弃。
- 本地偏好不保存 Cookie、CSRF、密码、令牌、完整会话或业务明细。
- CSV 只导出当前浏览器内已经加载并筛选后的 Mock 记录；没有调用服务端，也不冒充真实全量数据。
- CSV 对以 `= + - @` 开头（含前导空格）的单元格加安全前缀，避免表格公式执行。
- 证据文件只保存在当前浏览器内存，对象 URL 在移除或页面销毁时释放；没有上传到任何服务。
- 浏览器校验不是服务端安全证明；后续真实上传服务必须重新校验文件签名、权限、组织范围、病毒与内容策略。
- 任务深链使用严格白名单结构，不接受任意 URL、路径穿越字段或附加 URL 字段；路由守卫仍执行第二道门禁。
- 所有业务结果仍显式标记为 Mock，没有真实库存写入。
