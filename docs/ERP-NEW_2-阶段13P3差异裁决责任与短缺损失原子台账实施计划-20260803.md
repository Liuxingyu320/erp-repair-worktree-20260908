# ERP-NEW_2 阶段 13P3：差异裁决责任与短缺损失原子台账实施计划

> 日期：2026-08-03
>
> 分支：`codex/erp-new-2-rebuild`
>
> 基线：`ae2b16cb feat: define adjudication execution persistence contract`
> 范围：责任调整与短缺运输损耗两个不改变库存数量的原子效果；不接通执行入口，不处理受损库存、补发或退回

## 1. 结果目标

阶段 13P2 已冻结裁决动作执行的锁序与条件状态持久化，但五类物理效果尚无实现。只追加业务事实、不改变库存数量的两个效果可以先独立闭环：

- `responsibility_ledger`：把责任调整动作固化为不可变责任台账；
- `shortage_loss_ledger`：把短缺运输损耗核销固化为不可变损失台账。

这两个台账是差异处置的权威业务记录，不冒充财务总账凭证。未来若启用财务集成，应从这些不可变事实派生独立会计凭证并保留关联，不能回写或覆盖本台账。

本阶段实现可加入未来唯一执行事务的真实效果所有者，但不把它接入执行 Service、Controller、任务或配置。执行入口继续默认关闭并最终硬停止。

## 2. 审计依据

当前仓库没有满足 V2 差异裁决要求的责任台账或运输损耗台账：

- 旧调拨差异只有可覆盖的 `responsible_party` 和处理结果字段，不是追加式历史；
- 采购退货的 `responsibility` 是单据属性，不能承载调拨差异动作；
- 盘亏库存日志伴随真实库存扣减，不能用于“短缺未入库”的运输损耗；
- `inv_stock_ledger_detail` 描述库存位置和数量变化，短缺损耗没有目标库存可扣，不应伪造库存流水。

因此新增两个专用、只追加的业务台账，而不是复用旧字段或库存流水。

## 3. 成本与守恒补强

执行边界必须补入裁决时冻结的 `source_cost_price`：

- 从裁决头读取，不从当前商品或库存价格重新计算；
- 精度固定为 `decimal(18,6)`，必须非负；
- 差异总金额必须等于 `round(source_cost_price * discrepancy_quantity, 6)`；
- 动作数量和金额继续由计划守恒校验；
- 执行事件、责任台账和损失台账都保存同一成本快照。

任何成本、数量、金额、动作版本、事项版本或决定指纹不一致都必须在首个效果 DML 前失败。

## 4. 不可变台账结构

新增滚动 SQL：

`sql/erp_inventory_transfer_discrepancy_atomic_ledger_v2_20260803.sql`

责任台账与短缺损失台账均保存：

- 请求、事项、裁决、动作、动作前版本和动作序号；
- 收货、收货分配、发货、原调拨及发货分配锚点；
- 物料类型、物料、兼容商品标识；
- 差异/动作类型、责任方、数量、源成本价和金额；
- 决定指纹、执行事件指纹、裁决说明、动作说明和证据引用快照；
- 必需权限、操作者和发生时间。

唯一约束：

- 每个执行请求只能写一次同类台账；
- 每个动作前版本只能产生一次对应原子效果；
- 表只新增，不包含业务样例、默认 Gate、连接串、密码或种子数据。

## 5. 纯效果策略与事务所有者

新增纯策略 `InvTransferReceiptDiscrepancyAdjudicationAtomicLedgerPolicy`：

- 只接受已经由执行策略产生的 `PreparedExecution`；
- 仅允许 `dispatch`、`pending -> completed`、动作版本精确加一、无子流程引用；
- `responsibility_adjustment` 只能推导责任台账；
- 短缺 `transport_loss_write_off` 只能推导短缺损失台账；
- 受损运输损耗、报损、补发和退回全部拒绝，避免跨越尚未完成的库存或子调拨效果边界。

新增窄 Mapper，仅允许两个条件 `INSERT ... SELECT`。插入必须重新核对事项、裁决、动作的当前前状态/版本、数量金额、责任方、成本、决定指纹、权限和不存在先前效果。

新增 `Propagation.MANDATORY` 效果所有者：

- 调用方没有既有事务时必须拒绝；
- 根据纯策略唯一选择一个台账插入；
- 插入行数不为 1 时失败关闭；
- 不拥有入口 Gate，不更新执行事件、动作、计划或事项；
- 未来只能由唯一执行事务在“全部锁定和策略准备之后、执行事件与状态 DML 之前”调用。

## 7. 验证

定向验证至少覆盖：

- 源成本价进入边界、事件指纹和事件持久化；
- 两种允许效果的唯一分类与其他动作组合失败关闭；
- 只有既有事务可调用效果所有者；
- 每次恰好执行一个条件插入，0 行或多行均失败；
- Mapper 只有两个插入且不包含更新、删除或库存表；
- SQL 的加法、幂等、唯一键、成本/证据快照与无运行配置；
- 执行入口仍无 Mapper/效果所有者字段、无事务、无生产调用点。

随后运行库存模块完整离线 Reactor。全程不执行迁移、不连接数据库或网络服务。

## 8. 停止线

- 不实现受损隔离库存扣减、报损台账、序列号报废、补发或退回子调拨；
- 不把责任或损失业务台账宣称为会计总账；
- 不接通执行入口，不移除最终硬停止，不启用 Gate；
- 不执行 SQL，不启动 Docker、服务或中间件，不连接 MySQL、Redis、Nacos 或任何数据库；
- 不安装依赖，不修改 `.env`、端口、密码或密钥；
- 不删除旧前端，不合并、不推送、不操作其他 worktree。
