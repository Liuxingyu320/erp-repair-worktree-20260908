## 2. 为什么仍然只允许本地草案

阶段 13F 的浏览器安全只读投影有意不暴露后端写服务所需的内部 `factFingerprint`。本阶段没有伪造该指纹，也没有把内部并发依据降级为浏览器可编辑字段。

本阶段明确不包含：

- `requestId`、`factFingerprint` 或 `decisionFingerprint`；
- 真实金额分摊、库存执行状态或内部数据库标识；
- Writer、Gateway 写方法、HTTP POST Controller 或真实服务端命令；
- 幂等、并发冲突与审计落库的虚假模拟。

后续真实写入若要开放，应先独立设计由服务端签发的短时不透明 basis token，并绑定用户、组织、事项、版本和确认事实；该安全握手必须作为单独 Gate 审查，不能由当前本地草案推导或替代。
