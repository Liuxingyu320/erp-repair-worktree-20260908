   - 工作台聚合待办、异常、在途调拨和完成指标。

   - 收货确认只返回非持久化 Mock 回执，不改变库存或业务状态。

## 3. Mock 与隔离证明

- 新增调拨领域接口只通过 `AppGateways.transfer` 调用。
- 当前启动配置固定 `VITE_ENABLE_MOCKS=true`，由独立 Mock gateway 返回 fixture。
- 未配置 Mock 时 gateway 默认拒绝，不会回退连接任何业务服务。
- 原型运行源文件未引用旧 `erp-ui/src`、受保护原项目路径或 `BossERP_NEW`。
- 源码和测试目录没有软链接；依赖、构建、截图、报告、浏览器和本地配置全部被忽略。
- 本阶段没有启动 Docker，没有连接 MySQL、Redis、Nacos 或任何共享服务。

## 4. 设计与动效结论

- 视觉延续暖白、墨色、茶绿色和少量金色，桌面保持高信息密度。
- 手机采用单列任务卡、约 44px 触控区和固定唯一下一步。
- 外部参考只用于抽象的信息架构和动效研究，没有复制第三方组件代码、品牌或素材。
- 动效按高频生产力工具处理：布局即时切换，仅保留克制的 transform 反馈。
- 全局支持 `prefers-reduced-motion`，浏览器测试已验证减少动态效果路径。
