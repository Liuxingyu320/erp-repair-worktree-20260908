## 1. 目标

为未来 173 项页面迁移建立可扩展的全局功能检索入口，并把侧栏、移动导航与命令入口统一到同一份权限和功能目录。首批只暴露已经存在、具有路由且通过当前会话能力校验的工作台、待办、库存调拨和新建调拨，不显示未实现领域。

## 2. 设计研究转化

- 21st.dev 的“预览后复制提示词”模式只用于提炼信息结构，不复制 React/shadcn 源码；
- UI Prompt Library 的命令面板导航模式用于解决大规模 ERP 功能发现；
- React Bits、Magic UI 和 MotionSites 偏营销与展示，本切片不引入背景、光效、3D、持续动画或外部字体；
- Motion Primitives 的状态连续性只转化为焦点管理和明确的开关状态，不引入 Motion 运行时；
- Uiverse 的控件细节只转化为清晰的 hover、focus、active 与对比度规则，不复制站点组件代码。

外部参考的采用方式保持为“观察 → 提炼意图 → 用 Vue 3、现有设计令牌和本地组件独立实现 → 测试”。

## 3. 交互与动效决策

项目属于高频 ERP 生产力工具，采用 Emil 为主、Jakub 为辅：

- `⌘K` / `Ctrl+K` 是键盘高频入口，打开、过滤、选择和关闭均即时完成，不增加动画；
- 打开后焦点直接进入搜索框；`Escape` 关闭后焦点回到触发按钮；
- 结果使用标准链接/按钮语义，支持键盘浏览和回车选择；
- 对话框使用静态遮罩，无循环光效、缩放、视差、模糊入场或布局属性动画；
- 既有全局 `prefers-reduced-motion` 门禁继续覆盖全部过渡。

## 4. 技术设计

1. 扩展 `navigation.ts` 为可复用功能目录，字段包含展示面、分组、说明、搜索关键词、功能标识、权限和路由。
2. 新增纯函数：
   - 根据会话功能和权限筛选可见条目；
   - 根据中文、英文、路由和关键词做规范化搜索；
   - 分别投影侧栏/移动导航和命令面板条目。
3. 新增 `ErpCommandPalette.vue`：受控开关、可访问对话框、搜索框、空结果、结果选择、焦点进入和 `Escape` 退出。
4. `AppShell.vue` 接入全局快捷键、触发按钮、权限过滤和路由跳转；组织切换时仍复用现有 AppShell 重渲染边界。
5. 不新增依赖，不调用网络，不改变后端契约或真实运行配置。

## 5. TDD 顺序

1. 先为功能目录补充能力过滤、展示面投影和规范化搜索测试；
2. 先为命令面板补充打开聚焦、过滤、空结果、选择和 Escape 关闭测试；
3. 运行定向测试，记录新导出与组件不存在的 Red；
4. 实现最小功能并让定向测试转 Green；
5. 执行完整 `npm --prefix erp-ui-next run verify`；
6. 执行格式、隔离、依赖、外部资源和旧前端引用审计。

## 7. 验收

- 当前 Mock 角色只能看到自身同时具备功能和权限的条目；
- 未知功能、缺少权限、禁用功能和未实现领域默认不可见；
- 中文、英文关键词和路由检索可用；
- 键盘打开、聚焦、Escape 关闭、结果选择与触发点焦点恢复有组件测试；
- Prettier、ESLint、TypeScript strict、OpenAPI 静态门禁、Vitest 和 Vite 构建全部通过；
- 无 React、Tailwind、Motion、远程字体、遥测或新依赖。

- 不执行 `npm install`、`npm ci` 或任何联网依赖命令；
- 不写真实 `.env`、端口、凭据或运行数据；
- 不访问受保护原项目，不修改旧 `erp-ui/`，不删除、合并或推送。
