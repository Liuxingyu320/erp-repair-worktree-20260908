# ERP-NEW_2 阶段 13K：差异裁决依据令牌原子消费实施计划

## 1. 目标

把阶段 13J 的不透明 basis token 与阶段 13E 的唯一裁决事务合并为同一个失败回滚边界，使浏览器不再提交或获知内部 `factFingerprint`，并保证一次性消费不会与裁决计划、动作或事项状态部分提交。

本阶段仍不新增 Controller、HTTP/RPC、前端 Writer、权限菜单或运行时调用点。

## 2. 浏览器安全命令

新增独立命令契约，只接受：

- `requestId`；
- 不透明 `basisToken`；
- 事项 ID 和页面看到的事项版本；
- 裁决说明、证据引用和 1 至 20 个动作。

命令不包含 `factFingerprint`、双方确认事件 ID、决定指纹、金额分摊、裁决主键或执行状态。唯一裁决事务按令牌摘要锁定服务端 basis 记录后，才恢复内部事实指纹并构造既有纯裁决策略的内部 `Request`。

## 3. 固定锁序和新写路径

同一 `@Transactional(rollbackFor = Exception.class)` 中固定执行：

1. 在任何数据库访问前验证登录快照、精确权限和所选组织范围；
2. 使用有限组织范围锁定事项；
3. 按 `requestId` 锁定已存裁决；
4. 按原始令牌的用途域摘要锁定 basis；
5. 核验令牌仍为 `issued`、未过期、未消费，并重新核验用户、组织范围、事项版本、事实指纹和双方最新确认；
6. 由服务端 basis 构造内部裁决请求并运行既有数量/金额守恒与职责分离策略；
7. 条件插入裁决头、精确数量的动作并条件推进事项；
8. 最后条件更新 basis 为 `consumed`，绑定同一 `requestId`、裁决主键、消费人和消费时间；
9. basis 更新不是精确一行时抛出异常，回滚此前全部写入。

锁序不得因为新请求、并发冲突或重放改变。

## 4. 精确幂等重放

当 `requestId` 已存在时，事务仍按 case → request → basis 顺序加锁，并要求：

- basis 状态已经是 `consumed`；
- 原始令牌摘要与该 basis 精确匹配；
- `consumed_request_id` 和 `consumed_adjudication_id` 分别匹配已存请求与裁决；
- basis 的用户、所选组织、当前规范化组织范围、事项、消费前版本、事实指纹和双方确认事件与已存裁决一致；
- 当前事项仍是该计划推进后的版本和状态，动作、金额与决定指纹完整可重算；
- 当前用户仍拥有精确权限且当前组织范围仍覆盖事项。

已成功消费的令牌允许在 5 分钟过期后返回同一幂等结果，因为不会产生新写入；但必须证明最初消费发生在签发后且过期前。不同令牌、用户、组织、范围、请求或裁决结果不得借重放路径读取既有结果。

## 5. 持久化约束

扩展 basis Mapper：

- `SELECT ... FOR UPDATE` 仅按服务端 token 摘要读取一行；
- `UPDATE` 只能把完整匹配、未过期、未消费的 `issued` 行推进为 `consumed`；
- 不新增删除、续期、重置或重新启用方法；
- DDL 把 `consumed_request_id` 和 `consumed_adjudication_id` 改为各自唯一，形成一次消费与一次裁决的一一锚定。

原始 token 仍不落库、不进入 Mapper 参数或日志字符串。

## 6. 测试与验证

- 纯策略：issued 核验、消费意图、过期前消费、过期后精确重放、已消费新写拒绝、跨用户/组织/范围/事项/版本/事实/请求/裁决拒绝；
- 事务：固定锁序、服务端恢复指纹、消费最后执行、消费零行导致全事务异常、所有前置失败不消费；
- 重放：同一 token + request 返回原结果，不执行任何新 DML；不同 token 或消费锚点漂移失败关闭；
- Mapper：只允许一个签发 INSERT、一个 token 锁 SELECT 和一个条件消费 UPDATE；
- DDL：只创建/约束 basis 表，不执行数据库迁移；
- 完成库存模块离线 Reactor、新前端完整门禁、隔离和敏感信息扫描。

## 7. 停止线

- 不新增或调用 Controller、HTTP/RPC、消息消费者或调度任务；
- 不执行 DDL，不启动服务，不连接数据库或中间件；
- 不开放功能码、菜单、权限种子或默认前端运行时；
- 不执行补发、退回、报损、库存、物流或财务动作；
- 不删除旧前端，不合并或推送。

只有本阶段的同事务消费和精确重放全部验证后，后续阶段才可单独设计 HTTP 写边界。
