## 1. 目标

在已经完成的 HttpOnly Cookie、CSRF 和真实 HTTP 网关基础上，补齐浏览器可操作的认证入口：验证码读取、登录、首次会话恢复、会话过期提示、跨标签页过期传播和安全退出。所有业务网关仍须在完整会话校验通过后才可安装，任何失败不得回退到原项目或共享环境。

## 2. 冻结边界

- 浏览器只使用同源 `/api` 路径和 `credentials: include`，不得把访问令牌写入 JavaScript、URL、日志或 Web Storage。
- 登录请求只发送 `username`、`password`、`code`、`uuid`；验证码关闭时不得伪造验证码标识。
- 验证码、登录、会话和退出响应必须禁止缓存；验证码图片只以内联 Base64 数据展示，不加载外部资源。
- 初次探测 401 表示匿名用户；已经建立的会话收到 401 表示会话过期。两者都进入登录页，但过期状态必须提供明确提示。
- 登录成功后必须重新读取并严格校验完整会话，之后才能安装真实业务网关。
- 退出必须携带当前 CSRF 令牌、忽略组织上下文，并在本地清除会话和业务网关；失败时不得假装已退出。
- 登录后的返回地址只接受站内绝对路径，拒绝 `//`、反斜杠、控制字符和登录页自身，防止开放重定向与循环。

## 3. 实施步骤

### 步骤 A：认证契约与后端缓存边界

- 新建 `erp-ui-next/src/platform/auth/browser-auth.http.ts`，使用 Zod 严格解析验证码、登录和退出响应。
- 为验证码响应补充 `Cache-Control: no-store, max-age=0` 与 `Pragma: no-cache`，并增加网关处理器测试。
- 契约测试覆盖同源路径、Cookie 凭据、验证码开关、无令牌 JSON、CSRF 退出和异常响应失败关闭。

### 步骤 B：会话状态与路由

- 为会话 Store 增加 `anonymous` 与显式重载状态，确保匿名、过期、后端不可用三者语义不混淆。
- 新增公开 `/login` 路由；受保护路由在匿名或过期时跳转登录页，并携带安全的站内返回地址。
- 已登录用户访问登录页时返回工作台；后端不可用仍进入独立的“会话不可用”页。

### 步骤 C：登录与退出界面

- 新建 Vue 3 登录页，包含用户名、密码、可选验证码、错误摘要、重试和可访问焦点管理。
- 使用 ERP-NEW_2 自有设计令牌和普通 CSS；不复制外部组件，不引入 React、Tailwind、远程图片或运行时外部依赖。
- 参考既有设计库仅提炼“品牌区 + 任务表单”结构。品牌区只执行一次约 200ms 的 `opacity + transform` 入场，输入、键盘提交、错误和登录反馈即时；`prefers-reduced-motion` 下关闭非必要动效。
- 在真实 HTTP 模式的 AppShell 增加安全退出入口；Mock 隔离模式不伪造服务端退出。

### 步骤 D：验证与交付

- 补齐 Store、路由访问、认证 HTTP、登录页、AppShell 和 Bootstrap 的测试。
- 运行新前端格式、Lint、类型、单测和构建门禁；运行受影响的后端网关测试。
- 记录测试结果、剩余运行时验证项和“未启动服务、未连接数据库、未影响原项目”的证据，形成阶段检查点后提交。
