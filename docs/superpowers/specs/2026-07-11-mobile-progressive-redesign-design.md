# 手机端渐进式大改设计

**日期：** 2026-07-11<br/>
**范围：** 现有手机工作台、通用业务列表/详情/表单、库存工作台、个人中心、劳动合同、签约包以及共享移动弹层<br/>
**实施原则：** 在现有页面上大改，不新建一套应用，不替换既有路由、接口、权限、数据映射和业务动作。

## 目标

1. 彻底解决底部导航遮挡、弹层嵌套裁切、键盘顶起后按钮不可达和页面无法滚到底的问题。
2. 在不重写业务逻辑的前提下，统一所有移动页面的层级、颜色、间距、圆角、字体、列表、表单、状态和导航。
3. 保留已经修复的补货草稿编辑回显、删除草稿、错误字段定位和商品选择行为，并把同类能力推广到其他草稿型业务。
4. 让 320×568、375×667、390×844 以及带安全区的 iPhone/Android WebView 都能完成主要操作。

## 不做的事情

- 不创建新的移动应用、路由体系或平行页面。
- 不替换后端接口，不改变业务审批规则，不伪造数据。
- 不使用图片背景、重度玻璃、彩色渐变、卡片套卡片或悬浮胶囊导航。
- 不为了视觉改造拆掉已通过测试的权限、路由竞态防护、表单校验和数据边界。

## 视觉语言

采用克制的企业运营界面，而不是重新发明页面：

- 页面底色为暖白/浅灰，正文使用高对比墨色，翡翠绿只用于主操作和当前状态。
- 页面层级依靠字体、对齐、留白和细分隔线，不依靠大面积阴影和透明模糊。
- 内容区以连续列表和分组面板为主；独立业务对象才使用卡片。
- 圆角收敛为 8、12、16 三档；触控区最小 44×44px；正文基线 14–16px。
- 危险操作固定使用红色语义，处理中/提醒使用少量琥珀色，其他状态保持中性。
- 底部导航为不透明固定栏，统一高度、图标、激活态和安全区，不再由各页面分别设计。

## 布局与共享基础

### 设计令牌

新增共享移动样式文件，提供颜色、间距、圆角、阴影、底栏高度、安全区和可视视口变量。现有页面逐步引用这些变量；局部业务样式仍保留在原组件中。

### 页面壳

不重写现有模板，只统一以下结构契约：

1. 页面根节点占满动态视口，使用单一主滚动区。
2. 主滚动区底部内边距等于底栏高度、安全区和 16px 呼吸空间之和。
3. 顶部标题、上下文选择、主要操作和筛选按相同网格排列。
4. 底部导航复用同一视觉规则，现有跳转逻辑和权限逻辑不变。

### 弹层宿主

现有详情、表单、动作、实体选择和快速新建继续复用原组件，但统一到页面最外层弹层宿主：

- 每层弹层拥有明确的 z-index 和独立滚动体，不受父级 `overflow`、`transform` 或 `backdrop-filter` 裁切。
- 打开弹层时锁定真正的页面滚动容器，并隐藏/禁用底部导航。
- 标题和关闭按钮固定在顶部，操作区固定在弹层内部底部，中间内容是唯一滚动区。
- 通过 `visualViewport` 写入可用高度和键盘遮挡变量，输入聚焦后仍可滚到字段与操作按钮。
- 嵌套选择器关闭后恢复上层焦点与滚动位置。

## 页面改造

### 工作台

- 保留 `MobileWorkbenchShell` 和现有数据请求。
- 将“优先处理”提前，概览压缩成一行或紧凑分组；快捷操作放在任务之后。
- 去除照片背景和重度玻璃，任务列表改为连续分组列表。
- 加载、上下文缺失、权限错误、网络错误和空状态使用统一状态组件视觉。

### 通用业务页

- 保留 `feature/index.vue` 的配置驱动模式、服务、动作运行时和表单组件。
- 标题区缩短，搜索、状态筛选和主要操作压缩为首屏可用结构。
- 列表由独立浮卡改为连续分组行；长单号、商品名和摘要可换行但不得撑破布局。
- 草稿行显示编辑、提交、删除；非草稿只显示其权限允许的操作。
- 详情页使用清晰的键值分组和明细行；操作按钮位于可滚动内容之后且永不被底栏覆盖。

### 表单与物料选择

- 表单顶部保留标题与关闭，中间字段可滚动，底部操作固定在弹层内。
- 商品/礼盒选择器保持整屏可用高度，搜索和分类固定，结果列表独立滚动。
- 编辑草稿必须从详情模型恢复已选商品、数量、价格、仓库、门店、客户/供应商等标识字段。
- 校验失败先显示可读摘要，再滚动并聚焦首个错误字段；滚动目标计算使用动态可视视口。

### 库存、个人中心、合同与签约包

- 库存工作台沿用现有请求和入口，只统一壳、概览、任务列表和底栏。
- 个人中心保留资料读取/更新逻辑，移除独立蓝色视觉体系并接入统一导航。
- 合同页保留 PDF/合同加载逻辑，统一顶部栏、状态、列表与错误恢复。
- 签约包底部签署区改为弹层内部可滚动面板，不再依赖固定魔法高度；键盘出现时操作仍可见。

## 功能缺陷收口

1. 草稿编辑 payload 兼容后端 `unitPrice`/`price`、标识字段与明细字段差异，避免静默丢商品或重定价。
2. 后端已支持删除草稿的业务在移动端补齐删除入口；删除前确认，成功后关闭详情并刷新列表。
3. 普通调拨、采购、盘点等草稿动作与补货保持一致的编辑/提交/删除规则，但严格受现有权限约束。
4. 源单、实体选择或详情加载失败不得静默吞掉，必须显示可恢复错误状态。

## 可访问性与交互

- 所有可点击列表行为真实按钮化或提供等价键盘语义。
- 焦点可见，关闭/取消可恢复焦点，弹层内焦点不逃逸。
- 加载和成功使用 `status`，错误使用 `alert`；不能只用颜色表达状态。
- 尊重 `prefers-reduced-motion`，动效只用于状态过渡且不影响操作。

## 测试与验收

### 自动测试

- 先新增共享样式、弹层滚动、动态视口、统一底栏和草稿动作的源码契约测试。
- 保持现有非复制移动测试全部通过。
- 生产构建成功；已知复制测试文件和历史失败单独报告，不掩盖也不误报为本次回归。

### 视觉与交互验收

- 320×568、375×667、390×844 无横向溢出。
- 页面、详情、表单、实体选择、动作弹层均可滚到最后一个按钮。
- 软键盘打开时当前字段、错误提示和提交按钮可达。
- 底部导航不覆盖内容；弹层打开时底栏不可见且不可交互。
- 补货草稿编辑能恢复已选商品与数量，并提供编辑、提交、删除。
- 工作台、业务页、库存、个人中心、合同和签约包使用同一视觉体系。

## 实施顺序

1. 建立设计令牌、动态视口和底部安全区基础。
2. 修复共享弹层宿主、滚动体、键盘避让和动作对话框。
3. 改造通用业务页与补货草稿闭环。
4. 改造工作台、库存、个人中心、合同与签约包。
5. 收口其他草稿动作和接口字段兼容。
6. 运行移动测试、生产构建和同尺寸视觉回归。

## 回滚边界

所有改动限定在现有移动前端、相关 API 适配、必要后端草稿删除入口和对应测试。共享样式按页面逐步接入，可按阶段独立回退，不触碰数据库结构和部署配置。
