# 云盘 P0 体验修复设计

## 1. 目标

在不新增后端接口、不扩大云盘功能范围的前提下，修复桌面端与手机端四项高优先级体验问题：不可预览文件仍提供预览入口、手机端剩余额度文案错误、隐藏文件输入产生重复无障碍操作项，以及搜索范围表述不一致。

## 2. 范围

本次修改只涉及现有前端云盘页面、状态辅助函数和对应 Node.js 源码契约测试。

包含：

- 桌面端按文件实际预览能力显示预览入口；
- 手机端按文件实际预览能力决定文件主区域是否可点击；
- 手机端显示已使用、剩余和总额度；
- 桌面端与手机端隐藏文件输入退出键盘和读屏导航；
- 桌面端与手机端统一搜索范围文案；
- 为以上行为增加回归测试。

不包含：

- 批量选择、拖拽上传或文件夹上传；
- 手机端重命名、移动、删除、最近使用或回收站；
- 文件分享、版本历史或 Office 在线预览；
- 后端接口、数据结构或权限模型调整。

## 3. 交互设计

### 3.1 桌面端不可预览文件

`DriveNodeList` 使用与预览服务一致的 `isPreviewable(node)` 规则判断入口：

- 可预览文件：文件名按钮打开预览，并显示“预览”和“下载”；
- 不可预览文件：文件名不再作为预览按钮，只展示名称，并仅显示“下载”；
- 文件夹行为保持不变，文件夹名称和“打开”操作继续进入目录。

这样避免 XLSX、DOCX、压缩包等文件进入只显示“不支持在线预览”的无效弹窗。

### 3.2 手机端不可预览文件

手机文件列表按 `isMobilePreviewable(node)` 判断：

- 可预览文件的主区域保持按钮语义，点击进入预览；
- 不可预览文件的主区域改为非交互内容，仅保留行尾“下载”按钮；
- 文件夹的进入行为不变。

### 3.3 手机端容量

在 `mobileDriveState.js` 增加纯函数 `getMobileRemainingQuotaBytes(space)`：

```js
Math.max(Number(space.quotaBytes || 0) - Number(space.usedBytes || 0), 0)
```

空间卡片文案改为“已使用 X，剩余 Y，总额度 Z”。服务端数据异常导致已使用超过额度时，页面剩余量最小显示为 0，不显示负数。

### 3.4 上传控件无障碍

桌面端和手机端继续由可见按钮触发原生文件选择器。隐藏的 `input[type=file]` 增加 `tabindex="-1"` 与 `aria-hidden="true"`，避免键盘和读屏用户遇到重复上传入口；现有 `ref`、`accept`、`capture` 和 `change` 行为保持不变。

### 3.5 搜索范围

桌面端与手机端搜索框统一使用“搜索当前空间的文件和文件夹”。搜索仍由现有接口在当前选中空间内执行，不改变目录栈、分页或防竞态逻辑。

## 4. 代码边界

- `src/views/drive/components/DriveNodeList.vue`：只负责文件列表入口与语义；复用已有预览能力判断。
- `src/views/drive/components/DriveToolbar.vue`：只调整搜索说明和隐藏文件输入属性。
- `src/views/mobile/drive/mobileDriveState.js`：提供可独立测试的剩余额度计算。
- `src/views/mobile/drive/index.vue`：消费剩余额度函数并调整文件行、搜索文案和隐藏输入属性。
- `test/cloudDriveDesktop.test.js`、`test/mobileCloudDrive.test.js`：增加源码契约和纯函数断言。

不重构现有大组件，不改变 API 模块或后端契约。

## 5. 错误与边界处理

- `space` 缺失或容量字段为空时，剩余量按 0 处理；
- `usedBytes > quotaBytes` 时，剩余量钳制为 0；
- `canPreview` 为假或扩展名不在允许列表时，文件不提供预览入口；
- 下载能力和现有下载错误处理保持不变；
- 隐藏文件输入仍可由可见按钮程序化触发，不改变文件类型白名单。

## 6. 测试与验收

采用 RED→GREEN：

1. 在桌面测试中增加不可预览文件不应暴露预览入口、搜索范围文案统一和文件输入退出无障碍导航的断言，先验证失败；
2. 在手机测试中增加剩余额度正常值、超额钳制、不可预览文件非交互、搜索文案统一和两个文件输入退出无障碍导航的断言，先验证失败；
3. 实现最小修改后运行四个云盘聚焦测试；
4. 运行完整 `npm test`；
5. 运行 `npm run build:prod`，确认生产构建与密钥扫描通过。

验收标准：

- 不可预览文件不再出现无效预览入口；
- 手机端容量同时显示准确的已使用、剩余和总额度；
- 读屏和键盘导航只遇到一个可见上传入口；
- 两端搜索说明明确限定当前空间；
- 云盘聚焦测试、前端全量测试和生产构建均通过。
