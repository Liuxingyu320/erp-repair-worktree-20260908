## 3. 组件契约

`ErpEmptyState` 提供：

- 必填标题和说明；
- 可选眉题、图形插槽和操作插槽；
- 默认与紧凑密度；
- 受限的 `h2/h3/h4` 标题层级，避免复用时破坏页面层次；
- `role=status` 与 `aria-labelledby` 的可访问状态语义；
- 只使用 ERP-NEW_2 颜色、间距、圆角和阴影令牌的静态 CSS。

工作台两个嵌套面板使用 `h4` 空状态标题，并保留清晰的面板间距。

## 4. 动效决策

ERP 是高频生产力工作台。本切片按 Emil 为主、Jakub 为辅、Jhey 仅用于低频场景的权重主动选择静态空状态：

- 不使用入场动画、持续光效、脉冲、弹跳、3D、视差或粒子；
- 不依赖动画表达“没有数据”的业务事实；
- 通过稳定的图形焦点、标题、说明和可选操作表达下一步；
- 全局 `prefers-reduced-motion` 规则继续有效，但本组件即使关闭动画也无需降级。
