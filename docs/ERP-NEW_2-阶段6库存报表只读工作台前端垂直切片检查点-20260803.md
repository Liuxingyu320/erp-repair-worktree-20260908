## 2. 契约与安全边界

- 只覆盖 `GET /inventory/report/summary` 与 `GET /inventory/report/stock-warning`；后者是当前库存快照，日期只进入前者的 `params[beginTime]` / `params[endTime]`。
- 旧 summary 会向无成本权限角色返回成本字段；无 `inv:cost:view` 的旧 HTTP Reader 不请求该端点，并返回 `withheld_legacy_cost_contract` 静态能力状态。
- 有成本权限时才解析 `totalStockCost`、`purchaseAmount`、`salesCost` 和 `grossMargin`；金额保持十进制字符串，页面不自行重新计算业务事实。
- HTTP Reader 显式使用 `Dept-NumId`，不与 `X-ERP-Organization-Id` 双发；GET 不发送 CSRF。组织漂移在 fetch 前失败，跨组织预警记录拒绝整页。
- 新模型不保留跨单位总库存数量、行级成本价或总成本；预警日期参数因后端不消费而不发送。
- 默认启动只注入 ERP-NEW_2 脱敏 Mock，真实 Reader 未注入，未发出真实 HTTP 请求。
- 趋势、钻取、导出、商品选择器、报表配置、跨组织汇总和生产接线均未迁移。

## 3. 设计与动效结果

- UI Prompt Library 和 21st.dev 只影响“库存健康 → 经营摘要 → 筛选口径 → 预警明细”的信息层级；Motion Primitives 只影响成功/失败状态连续性。
- 页面由 Vue 3、现有设计系统和普通 CSS 独立实现，没有复制外部代码、提示词正文、素材或品牌组合。
- 未引入 React、Tailwind、Motion、GSAP、远程字体或新依赖；没有动态背景、光效、循环、列表入场或布局动画。
- 只保留 140ms 可中断按钮反馈，`prefers-reduced-motion` 会关闭过渡；状态始终有文字，不依赖颜色或动画。
