## 1. 本检查点结论

本阶段在 ERP-NEW_2 隔离工作树内，为调拨列表、详情、不可变修订历史和 Excel 导出建立了统一的服务端成本权限边界，并将处理中与历史记录导出接入新前端工作台。

本检查点证明：

- `inv:transfer:*` 业务权限不再隐含成本读取权，无 `inv:cost:view` 时服务端主动清空调拨单头、申请明细、发货明细和修订快照中的成本字段；
- 处理中与历史记录使用两个独立导出权限和状态范围，继承当前精确组织、服务端筛选与数据范围；
- 同步导出在 SQL 层只探测 10,001 行，超过 10,000 行明确拒绝，不执行无界结果加载；
- Excel 使用显式列白名单，普通角色不含参考总价，任何角色都不导出跨计量单位可能误导的总数量；
- 前端导出必须经过二次确认，并在请求前后复核组织、导出权限和成本权限；
- 本阶段没有启动任何服务，也没有连接数据库或中间件。

## 2. 后端安全闭环

### 2.1 成本字段策略

新增小型 `InvTransferCostVisibilityPolicy`，由 Controller 统一复用：

- 管理员或精确持有 `inv:cost:view` 的用户保留成本字段；
- 其他用户收到的 `totalAmount`、申请明细 `costPrice/amount`、发货明细 `costPrice`、修订头 `totalAmount` 与修订明细 `costPrice/amount` 均为 `null`；
- 列表、处理中、记录、详情和修订历史响应统一设置 `Cache-Control: no-store, max-age=0` 与 `Pragma: no-cache`；
- 前端隐藏仅负责展示，服务端脱敏才是安全边界。

### 2.2 有界组织范围导出

新增专用 `InvTransferExportService`，不复用会加载审批摘要的工作台列表路径：

- 先通过既有门店/仓库作用域服务验证所选组织，再解析其可读部门 ID 白名单；
- 空组织范围使用不可命中的 `-1` 失败关闭，不退化为全量查询；
- 主动移除请求对象中可绑定的 `dataScope`，禁止客户端 SQL 片段进入 Mapper；
- Mapper 使用参数化 `limit #{params.rowLimit}`，固定探测 10,001 行；
- 返回超过 10,000 行时抛出明确业务错误，不生成工作簿。

### 2.3 权限与列白名单

- `POST /inventory/transfer/export` 继续使用 `inv:transfer:export`，只允许处理中状态；
- `POST /inventory/transfer/records/export` 使用 `inv:transfer:records:export`，只允许终态历史记录；
- 两个端点都设置完整 no-store 响应头，并在输出前再次执行成本策略；
- 基础列只包含单号、调出/调入组织、状态、明细行数、类型、关键时间和关闭原因；
- 仅成本查看者增加参考总价，所有白名单均排除 `totalQuantity`。

## 3. 新前端闭环

### 3.1 HTTP 与文件合同

- 新增调拨导出 HTTP Gateway，按范围调用正确 POST 端点，并发送当前组织头、CSRF 与唯一请求 ID；
- 只传递已生效的单号、状态和调拨类型，不把页面分页伪装成全量导出范围；
- 状态筛选必须属于所选导出范围，否则在发起网络请求前失败关闭；
- 响应必须声明 no-store，只接受 XLSX 或二进制流 MIME，拒绝空文件和超过 25 MiB 的响应；
- 文件名由客户端固定为 ERP-NEW_2 安全名称，不信任服务端或响应头提供的路径片段。

### 3.2 显式确认与漂移保护

- 处理中与历史导出按钮分别按 `inv:transfer:export`、`inv:transfer:records:export` 显示；
- 弹窗冻结当前组织、已生效筛选、导出范围和成本列可见性，并展示 10,000 行同步上限；
- 确认前及响应返回后再次比较组织、导出权限和成本权限，任一漂移都不下载文件；
- 成功下载使用短生命周期 Blob URL 并立即释放；失败保留弹窗和筛选，允许用户核对后重试；
- 原“本页 CSV”保留为明确的纯本地功能，不冒充服务端范围导出。

### 3.3 设计参考边界

交互继续遵循 `docs/ERP-NEW_2-前端设计参考与使用约束.md`：吸收 21st.dev、React Bits、UI Prompt Library、Magic UI、Motion Primitives、Uiverse 与 MotionSites 对信息层级、状态连续性和局部反馈的启发，但未复制第三方代码、素材、提示词或品牌。导出属于高影响数据操作，因此使用克制的确认浮层和即时状态反馈，不添加干扰任务效率的装饰动效。
