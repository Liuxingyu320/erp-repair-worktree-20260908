# 用户管理列表手机号展示决策

日期：2026-07-30

适用范围：系统管理 → 用户管理列表

## 决策

用户管理列表允许直接展示完整手机号，不要求对手机号进行脱敏。

因此，当前用户列表查询直接返回 `sys_user.phonenumber` 属于符合产品要求的行为，不再作为隐私回归或发布阻断项处理。

## 对现有检查的影响

- 2026-07-30 项目整体审查中提出的“用户列表手机号未脱敏”问题关闭。
- `SysUserManageMapperSourceTest` 中要求列表使用脱敏手机号投影的断言，已与本决策不一致；后续整理测试门禁时应按本决策调整。
- 本决策不要求立即修改业务代码。

## 范围边界

本决策只覆盖系统用户管理列表，不自动扩展到操作日志、审计记录、接口调试输出、身份证号、银行卡号、工资或其他敏感数据场景。
