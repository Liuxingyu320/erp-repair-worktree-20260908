# P06 监控服务启用前核验

2026-09-13 阿里云只读证据未观察到本实例运行 ERP monitor/job，9100未监听。因此这是条件性源码加固，不是“线上匿名漏洞已确认并修复”。

代码将管理员与机器注册账号分离：管理员使用外部 ERP_MONITOR_ADMIN_USERNAME/PASSWORD；注册客户端仅在 ERP_MONITOR_REGISTRATION_ENABLED=true 且提供独立 ERP_MONITOR_REGISTRAR_USERNAME/PASSWORD 时启用。缺少有效管理员凭据会阻止服务启动，不会退回匿名模式或默认密码。不要把密钥提交到源码或验收报告。

机器注册只允许 Basic 身份的 POST /instances 和 DELETE /instances/{id}。该账号无法读取实例清单、代理 Actuator、配置或监控页面。客户端须配置 spring.boot.admin.client.username/password 为专用注册账号；不要复用管理员账号。浏览器管理操作仍需要管理员会话和 CSRF；唯一匿名动态接口是 GET /actuator/health，并限制健康详情。以上路径均包含实际 Spring Boot Admin context-path。

发布前需核验真实 Nacos/外部配置的上下文路径、账号/角色绑定、所有客户端注册配置、反向代理与网络监听/安全组。记录匿名访问、错误凭据、机器注册/反注册、机器访问代理被拒绝、管理员登录/会话操作/CSRF等真实HTTP结果。设置或轮换外部凭据、改变线上访问范围和启用服务未在本轮执行。

回滚顺序：先停止或回退 monitor 应用，再还原该发布的外部配置；保留既有客户端运行与回滚副本。不能用匿名放行作为恢复注册的临时手段。
