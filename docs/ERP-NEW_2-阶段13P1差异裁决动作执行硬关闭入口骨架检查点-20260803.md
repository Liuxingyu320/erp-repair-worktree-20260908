# ERP-NEW_2 阶段 13P1：差异裁决动作执行硬关闭入口骨架检查点

日期：2026-08-03

分支：`codex/erp-new-2-rebuild`

基线：`bc2db52a feat: define adjudication execution lifecycle`

## 1. 结果

阶段 13P1 已建立一个默认不可执行、误配置后仍不可执行的差异裁决动作入口骨架：

- 内部命令只携带请求 ID、案件/裁决/动作 ID、案件/动作版本、命令和异步效果引用。
- 命令不接受效果类型、数量、金额、责任方、操作者或权限；这些字段未来只能来自锁定后的服务端权威事实。
- 写入口同时要求 `write-enabled` 与 `effect-boundary-ready`，两个 `@Value` 默认值均为 `false`。
- 主资源配置没有写入上述开关。
- 即使两个条件被外部误设为 `true`，服务仍固定拒绝，因为持久化和物理效果边界尚未实现。
- 服务只依赖 Gate，没有 Mapper、Gateway、数据库模板、消息生产者、HTTP 客户端或事务注解。
- 生产源码中没有 Controller、RPC、消费者、调度器或其他调用点引用该服务。
