## 1. 检查点结论

新前端骨架已建立全局功能检索入口。侧栏、移动导航和命令面板现在由同一份功能目录投影，并同时通过已知功能与权限校验；当前 Mock 角色可见 3 个主导航入口和 4 个命令入口，未实现领域、未知功能、禁用功能或缺少权限的入口默认不可见。

用户可以点击顶部“搜索功能”，或使用 `⌘K` / `Ctrl+K` 打开面板；搜索支持中文标签、英文关键词和路由片段。打开后焦点进入搜索框，`Escape` 关闭后焦点返回触发按钮，选择结果后使用 Vue Router 导航。

## 2. 设计与动效结果

- 只采用外部参考中的命令式导航信息架构，没有复制外部组件、提示词正文、视觉品牌或素材；
- 使用 Vue 3、既有设计令牌和普通 CSS 独立实现；
- 没有新增 React、Tailwind、Motion、远程字体、CLI 或依赖；
- 键盘入口、搜索、选择和关闭是高频生产力操作，全部即时完成，不播放动画；
- 对话框通过焦点进入、焦点圈、焦点约束、明确结果层级和焦点恢复表达状态；
- 全局 `prefers-reduced-motion` 基线继续生效。
