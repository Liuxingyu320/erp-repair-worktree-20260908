## 1. 本检查点结果

已在独立 `erp-ui-next/` 设计系统中增加两个领域无关的 Vue 3 严格类型组件：

- `ErpTaskStatePanel`：将当前状态、当前等待、唯一下一步、业务说明和可选辅助信息组成同一个具名任务区域；
- `ErpTimeline`：用有序列表表达过程节点，支持状态文字、处理人、时间、说明、当前节点和空记录失败关闭提示；
- 时间线数据契约位于独立 TypeScript 类型文件，不从 Vue SFC 泄漏业务类型；
- 调拨审批页已作为第一个消费者，显示当前审批责任、等待节点、唯一下一步与语义化审批进度；
- 页面原有重复的审批轨迹 DOM/CSS 已被通用组件取代，审批契约、Gateway、Mock 数据、路由、权限、原因校验和请求幂等未变。

## 2. 可访问性与交互契约

- 任务面板是由内部标题命名的 `region`，可选用 `h2/h3/h4` 维持所在页面标题结构；
- 状态使用文字徽标和静态视觉语义，不仅靠颜色；
- 时间线使用 `<ol>` / `<li>`，当前节点使用 `aria-current="step"`，有权威时间时使用 `<time datetime>`；
- 没有权威过程数据时显示可读屏的空记录状态，不伪造历史节点；
- 窄屏下任务事实、状态和时间线内容改为单列，不依赖横向滚动。

## 3. 动效与外部设计参考决策

本切片将 ERP 视为高频生产力工具，采用 Emil 为主、Jakub 为辅的权重：

- 任务面板与时间线本身没有新的 animation、keyframes 或 transition；
- 删除调拨审批页原有 180ms 整页入场动画，因为它是高频阅读界面且动画不承载业务含义；
- 不使用循环、脉冲、弹跳、3D、粒子、大面积缩放或视差；
- 全局 `prefers-reduced-motion` 降级继续有效，关闭动效不影响任务完成；
- 21st.dev、React Bits、UI Prompt Library、Magic UI、Motion Primitives、Uiverse 和 MotionSites 只继续作为信息层级和质感研究输入，本轮没有复制代码、素材或提示词。
