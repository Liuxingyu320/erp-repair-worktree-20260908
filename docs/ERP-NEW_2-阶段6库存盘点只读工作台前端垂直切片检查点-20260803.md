## 2. 契约与运行边界

- 只覆盖 `GET /inventory/stockCheck/list`；详情、新增、候选人、指派、录入、提交、审批、轨迹、撤回、重盘、取消、删除和导出均未迁移。
- HTTP Reader 显式使用 `Dept-NumId`，不与 `X-ERP-Organization-Id` 双发；GET 不发送 CSRF。
- `expectedOrganizationId` 在 `fetch` 前阻止组织漂移，解析后拒绝其他组织记录和冲突的 `shopDeptId/warehouseId`。
- 日期参数严格为 `params[beginCheckDate]`、`params[endCheckDate]`；前端不发送 `scopeDeptIds`、`dataScope` 或任意 Mapper 参数。
- `totalDiffQuantity` 可能混合不同单位，因此新模型不保留；审批实例、事件键、失效快照和嵌入成本信息也被契约丢弃。
- 默认启动只注入隔离 Mock；真实 Reader 未进入默认运行时，本检查点没有发出真实 HTTP 请求。
