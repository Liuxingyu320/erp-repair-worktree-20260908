## 5. MySQL 5.7.31 干净范围复验

- 使用 Oracle 官方归档 MySQL Community Server 5.7.31 macOS x86_64 原生包，经 Rosetta 运行。
- 下载包 MD5 为 `d4f3ecaa960f987c225fb8aada8c4bf0`，与官方归档值一致。
- 临时实例只绑定 `127.0.0.1:3357`，数据库名包含 `rehearsal`，凭据只存在于执行进程。
- 基线只读导出来自既有非业务隔离快照；MySQL 8.0 专属 `utf8mb4_0900_ai_ci` 仅在导出流中映射为 MySQL 5.7 可识别的 `utf8mb4_general_ci`，没有修改源快照或项目迁移。

三份迁移按规定顺序连续执行两遍，两轮签名相同：

```text
21:1:2:6:2:4:36:2
21:1:2:6:2:4:36:2
```

结构签名为 `21:2:1:1:0`：健康证 21 列、唯一索引 2 个索引列、负责人字段 1、负责人索引 1、重复当前健康证员工 0。

负责人预检低敏计数为 `0:2:0:11`：无效负责人 ID 0、只有历史姓名无稳定 ID 2、姓名快照不一致 0、未就绪责任节点 11。readiness SQL 执行通过，Java 对账测试通过；记录不保存员工姓名或其他敏感字段。
