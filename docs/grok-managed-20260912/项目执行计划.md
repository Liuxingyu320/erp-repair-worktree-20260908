## 项目经理的验收方式

1. 给 Codex 实施代理明确目标、可改文件、已确认规则及边界；回收实际差异和交付说明。
2. 核对差异与来源，检查错误对象、过期响应、权限、重复请求、金额及版本等关键路径。
3. 由 Codex 在独立目录执行必要测试，失败由 Codex 修复。涉及高风险并发、工资、库存等时增加独立审查。
4. 保存每次任务输入、实施代理回复、变更清单、命令与结果；通过、失败、跳过分开记录。
5. 实际界面、真实岗位、数据库集成、设备和生产验收分别记录，不把源码检查或方法测试写成线上通过。
