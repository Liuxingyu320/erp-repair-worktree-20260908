# S11 表单设计草稿验收

Codex 直接实施；本地源码与实际 Vue/工具测试通过。范围是设计器页面、一个草稿工具和新增测试，不自动运行生成代码或发布表单。

修改后自动保存到本机当前账号/组织下。每个编辑窗口保存独立记录，刷新自动恢复最近有效记录，也能按保存时间选择草稿恢复。字段、布局、表单属性和选中项一并恢复，新增组件编号从树中重新核定；异常大内部编号重新编号且保留字段名/选中项。原共享默认配置改为每页独立副本。

支持 JSON 草稿导入导出。导入检查格式版本、大小、层级、组件种类、渲染所需选项形状和重复身份，拒绝渲染事件/原型注入。空设计与未完成字段名可保存，导出代码仍用原生成器校验；导出草稿可保留尚未能恢复的原内容。读取文件或确认期间出现新编辑/换账号会拒绝覆盖。

账号或组织切换前将待保存内容同步写回原窗口记录，不写到新账号键。存储失败保持当前编辑并可导出；切换前失败的快照在当前页面实例内按原账号暂存，切回后恢复/重试。本机存储被禁用或已满时不宣称持久保存，关闭/刷新仍有未保存内容时保留浏览器离页提示。已损坏记录不自动删除；草稿仅保存在当前浏览器，未同步服务器。
