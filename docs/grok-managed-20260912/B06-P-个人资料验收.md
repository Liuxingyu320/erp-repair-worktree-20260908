# B06-P 个人资料显示、分区与离页验收

Codex 直接完成 S03、S09、V01，按 D10/D11 执行。手机分为个人编辑、HR 档案和修改密码；个人编辑固定保存栏，HR 资料只读。共享日期显示工具只缩短有效完整 ISO 日期时间，公司/职位中普通大写 T 不再导致截断。PC 仅接入显示工具，用户 API 仅为 getUserProfile 新增严格布尔 silentError 可选项。

编辑离页提供保存后离开、放弃修改、继续编辑；失败与等待期间的新输入保留，未完成写入不能绕过。真实 Router 导航先取消原跳转，决策完成后重放第一个目标，避免第二次导航取消第一次后再也不能离开。缓存重入首次加载未完成时重新读取；旧读写按页面和账号隔离。硬刷新在存在草稿或进行中写入时提醒。明文密码与银行卡不持久化到浏览器存储或公开用户对象。

本地回归：新增 draft/navigation 19 场景/组、独立真实 Router/生命周期 14 场景、PC profileSaveRoundTrip 11 场景与既有 mobileProfileMaintenance 脚本全部通过，失败/跳过均为 0；Node runner 为 4 个脚本入口，不与内部场景重复累加。新增读取 API 测试核对缺省、false、字符串 true、严格 true 及 URL/method/data 注入被忽略。独立复核发现的导航取消、首次读取重入、写入中硬刷新三项问题已修复。

浏览器验收使用实际 SFC、Vue 2、Element UI、原 scoped CSS、原移动样式及合成数据，所有 API 为本地模拟。截图与 notes.md 位于 review-b06p/browser。390×844、320×640、390×480 均核对；末项与保存栏可同时使用，没有横向溢出；HR 只读、三选项弹窗、继续编辑保留内容、固定按钮保存中及成功状态可见。390×480 只模拟高度缩小，不能当作 iOS/Android 真键盘验收。早期未正确套用 scoped CSS/视口的截图保留为失败过程，不作验收依据。
