# B08-D 假期额度界面与政策重核交付

ATT-U1 / D22 的前端阶段已完成本地验收。员工可查看各假种可用、审批占用、已使用额度及来源有效期；没有匹配政策时显示“待核对”。HR 按本人权限搜索员工、分页看流水、按原额度桶单位和规则版本做调整；政策和公司/工作地映射使用明确字段维护，新政策先保存草稿再单独核对发布。主管可直接从已日结加班来源核定转休，专岗入口不依赖额外日结查看权限。

员工填写假种、开始/结束、实际申请天数、原因与证明附件；DAY整天、HALF_DAY半天、MIXED精确天数、旧分钟制兼容。不按自然跨日跨度猜实际天数，不猜480分钟或法定额度。标准九种假与额度假须HR审批，年假/调休必须使用额度；未配置政策或工作地映射须HR补齐。

保存时冻结政策来源与版本。HR改政策后，原草稿可使用只读“重新核对当前请假政策”入口，显示原/当前规则、换算与本次扣减，确认仅修改未保存表单，再保存或提交。预览绑定员工、门店、草稿ID、rowVersion与完整申请输入；期间冻结表单；切店/切人/更改输入/响应不匹配均不采纳。当前政策的申请单位在确认后生效；不以陈旧类型列表阻止取得新政策。

保存/提交超时沿原冻结命令核对，未知结果保留原意图；后续新输入即使不完整，也不阻止核对上一笔。仅业务已明确拒绝且权威草稿仍等于原基线才解除尝试，允许重核政策。比较包含政策快照，同样业务字段的旧政策不冒充新政策已保存。普通HR调整与转休同样保留原作用域、精确ID/金额/版本及幂等请求。
