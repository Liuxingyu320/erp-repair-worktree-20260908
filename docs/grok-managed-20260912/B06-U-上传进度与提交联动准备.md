逐文件队列保留原始文件供显式重试，每次重试产生新的文件/uid。取消先退休对应操作，再 abort 该上传；旧成功/失败/进度回调不再作用于新操作。压缩中的取消也不能稍后继续发请求。未知网络结果不在后台自动重新上传，用户可选择重试；业务提交仅使用收到完整成功响应的安全文件地址。

正式提交联动优先采用 Element UI 已有 el.form.addField/removeField 与 inject elForm 注册独立上传校验字段，其他表单字段不禁用；实际 Form.validate 的 callback/promise/reset/clear 生命周期均需验证。当前已核对 10 个页面的共17个共享上传入口：除 MobileFormSheet 原生表单外，现行可写入口均经 el-form.validate；旧劳动合同企业章写UI/后台已关闭，不恢复旧写入口。手机表单需绑定上传状态并在 emitSubmit 同步拦截，保留正常 emitInput。

组件以所属 elForm.model 身份、账号/组织、外部value变化退休旧批次；同组件自身成功/删除/排序的 input 回流不得误清当前队列。无elForm的手机入口用显式实例/表单上下文。完整扫描其他别名与动态入口仍在实施验收内。

复用 Element UI 实际 upload ajax，包装回调先判断本批次/上下文有效性，再进入 Element 原始回调，避免 abort/销毁后的迟到回调操作已移除列表。删除按钮改原生 button，保留 filename accessible name 和可见焦点；该处已改，现有上传两脚本通过，但尚未标整批验收。
