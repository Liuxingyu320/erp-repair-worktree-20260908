## 请求错误边界

`getUser` / `getUserPii` / `addUser` / `updateUser` / `updateUserPii` / `previewUserDerivedProfile` 增加可选末位 config，只读取 `silentError === true`，不把其它字段并进 URL/方法/身份/载荷。默认调用 `silentError` 不为 true，拦截器仍会提示。

本页有会话判断的请求传 `{ silentError: true }`。当前会话失败仍明确提示（资料加载、基础保存、创建、PII 部分成功）；过期错误静默且不写进 B。`getUser` 失败已 catch：当前会话可再次打开重试，旧失败不污染 B。派生预览仍安静失败。`persistUserForm` 直接调用仍可拒绝；`submitForm` 入口继续消费已处理拒绝。未加测试级 `unhandledRejection` 屏蔽。
