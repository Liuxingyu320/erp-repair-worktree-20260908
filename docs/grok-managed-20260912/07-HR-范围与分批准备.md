# B07 人事与合同：只读范围与分批准备

2026-09-12。B09 已完成本地验收。本文仅为项目经理准备，没有修改 HR 业务源码、执行 HR 测试、访问数据库或再次调用 Grok。剩余实施按用户新授权由 Codex 执行，须由主项目经理先认领本节精确范围。

## 已确认语义

- D18：普通调岗不要求重填工资、不提示“工资不变”、不发送薪酬结构确认书。有工资操作权限者才可选择“同时调整工资”，只有实际调薪才进入新的薪酬确认书流程；不能仅因组织/岗位变化或工资版本字符串变化就当作实际金额调整。
- D23：历史合同补签保存合同当时工资，不覆盖现行档案工资。真正更改现行工资走正式调薪。普通新合同继续“核对Excel → 生成合同 → 自动同步”，不增加额外工资确认按钮、手填金额或日期。
- D19/D20：员工档案办理转正、办理续签，衔接现有正式动作及权限并保留动作/历次合同记录。不能用普通资料 PATCH 模拟转正续签。
- 发送时点没有新授权：复用现有 HR 确认发送、outbox 和待发送任务；不能自行加“审批完成立刻发送”或“员工签署后才生效”。
