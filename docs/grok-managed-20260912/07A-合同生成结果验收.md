## 最终行为

- 按后端 `OaSignOnboardGenerateResult` 契约核对逐行结果及汇总：请求行完整且不重复，状态限于 GENERATED / REUSED / BLOCKED / FAILED，各项计数与实际结果一致。
- 空响应、未知状态、缺行、错误行和计数不一致保留原请求号及工资同步恢复状态，提示结果未确认，不宣布已生成。
- 全部失败或阻塞停留处理步骤；部分完成准确显示生成、复用、待处理、失败数量，刷新成功后允许查看已完成合同；完整成功或复用才提示可预览。
- 已知生成成功但刷新失败保留请求号及恢复状态，不假定列表已就绪。刷新必须返回原批次 ID 和有效、无重复行的 rows 数组；空/null/错批次/缺 rows/坏行不覆盖原批次。生成期间重复点击不发第二次命令。
- 关闭、切换批次、重开或组件销毁后，旧工资同步不继续发生成请求，旧响应不覆盖新批次提示、列表或忙碌标志。
- 原 Excel 工资来源、同步调用与金额校验保持原样；生成仍不自动发送。签名在前的合同继续单独预览和发送最终文件。历史补签规则不在本批修改。
