# 07C 历史补签工资隔离任务

2026-09-12，Codex 直接实施，依据 D23，根项目经理已批准继续。

## 业务口径与边界

历史补签保留合同当时工资，不能覆盖现行员工档案；普通合同仍是核对 Excel、点击生成、自动同步工资，HR 手动发送时点保持。真正现行调薪沿正式调薪。

同步工资先于 generate 保存历史确认，因此不能仅依赖未必已落库的 historical_supplement。服务端沿既有合同日期规则识别历史：合同开始日早于业务今天，或已有历史标记。历史仅追加明确类型 HISTORICAL_CONTRACT_EXCEL 的不可变来源，不更新档案、不改当前来源指针、不写代表现行工资入档的旧审计。生成阶段继续要求原有历史确认和原因，不增表单。

现有来源表保存合同工资及来源身份；现有包来源表保存不可变绑定。历史确认、生成、重用和发送分别核对员工、批次、源行、文件哈希、合同日期、五金额；绑定/发送还核对源行、任务、包关联。普通合同当前来源锁与并发拦截保持，旧签字优先兼容例外不扩大。不修改前端、Excel 工资解析、工资来源 DDL、菜单权限或 Lifecycle。
