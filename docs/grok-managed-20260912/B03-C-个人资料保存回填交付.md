# B03-C 个人资料保存回填交付

## 当前代码

允许文件：`userInfo.vue`、`erp-ui/src/api/system/user.js` 仅 `updateUserProfile`、新测试与本交付。未改用户管理主页面、其他 API 函数、父 profile 页。

- deep watcher 按已同步快照跳过自身回写；同对象外部改昵称/联系人仍回填；换新 user 对象整表回填。
- 同对象权威 **profile 以 incoming 为准**（含删除/清空），只读展示不残留。表单仍只接纳 incoming 相对 previous 真正变化的字段，其它本地编辑保留；权威字段变化（含 pending 保存后改昵称）必须写进表单，不能因 dirty 整段跳过。
- 保存代次隔离：外部权威变化、关闭、销毁后，旧成功/失败/finally 不再改对象、输入、提示或 busy。
- `updateUserProfile(data, options)` 只追加 `silentError: userSilentError(options)`，不展开 options，url/method/data 不被覆盖；默认仍会走全局错误层。
- 本页调用 `{ silentError: true }`。当前有效失败用页面 `msgError` 并保留输入；过期/关闭/销毁失败静默。
- 缺省字段 `$set` 回填；银行卡明文不进公开 user/profile；校验中/保存中忽略重复 submit；未保存提示保留。
