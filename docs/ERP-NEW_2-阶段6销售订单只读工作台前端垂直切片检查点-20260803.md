## 2. 契约与安全边界

- 只覆盖 `GET /inventory/sales/list`；真实 Reader 保持未注入，默认启动仅使用 ERP-NEW_2 脱敏 Mock。
- 请求只发送 `pageNum`、`pageSize`、`orderNo`、`orderTitle`、`customerName`、`status`、销售日期区间和一个 `Dept-NumId`；GET 不发送 CSRF，也不接受门店 ID 或数据范围参数。
- 请求前校验当前组织未漂移，解析后逐行校验门店归属；任一跨门店记录都会拒绝整页。
- 领域模型保留销售单号、标题、客户、门店、金额、销售日期、状态、经办人、创建时间和备注。
- 客户 ID、门店兼容 ID、申请人/部门 ID、详情、内部更新字段与数据范围参数全部在契约边界丢弃。
- `totalQuantity`、`deliveredQuantity` 与 `remainingQuantity` 可能跨商品单位聚合，因此不进入新模型或指标；金额保持十进制字符串并用 Decimal 展示。
- 当前端点缺少显式 `Cache-Control: no-store` 证据；服务端缓存策略、版本化 OpenAPI 和生产等价负向测试完成前，不注入真实 Reader。
- 详情、我的订单、新建、编辑、保存、提交、取消、导出、配送通知、发货、销售退货和生产接线均未迁移。

## 3. 设计与动效结果

- UI Prompt Library 与 21st.dev 只影响“门店范围 → 指标 → 筛选 → 履约明细”的信息层级；Motion Primitives 只影响成功/失败状态连续性。
- 页面由 Vue 3、现有设计系统和普通 CSS 独立实现，没有复制外部代码、提示词正文、素材或品牌组合。
- 未引入 React、Tailwind、Motion、GSAP、远程字体或新依赖；没有动态背景、光效、循环、列表入场或布局动画。
- 只保留 140ms 可中断按钮反馈，`prefers-reduced-motion` 会关闭过渡；状态始终有文字，不依赖颜色或动画。
