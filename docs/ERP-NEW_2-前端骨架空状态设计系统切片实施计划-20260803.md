# ERP-NEW_2 前端骨架：空状态设计系统切片实施计划

> 日期：2026-08-03
>
> 分支：`codex/erp-new-2-rebuild`
>
> 基线：`683283aa feat: add discrepancy atomic business ledgers`

## 1. 结果目标

`erp-ui-next/` 已经拥有独立的 Vue 3 工程骨架、应用外壳、设计令牌、工作台和库存调拨原型。本切片不重新初始化或覆盖既有成果，而是补齐一个可复用、可访问、符合高频 ERP 语境的空状态组件，并让工作台的空任务与空调拨阶段不再显示无解释的空白列表。

## 2. 设计依据

- 参考 UI Prompt Library 的 Dashboard Empty State 结构：图形焦点、明确标题、简短说明和可选下一步。
- 参考 21st.dev 的组件对比方法，只提取结构和交互意图，不复制组件代码。
- 采用 Motion Primitives 的状态连续性思想，但不引入 React Motion 或 Tailwind。
- Magic UI、React Bits、Uiverse 和 MotionSites 只提供低频空状态的质感灵感；核心工作区不使用持续光效、粒子、3D、弹跳或营销式背景。
- 动效权重为 Emil 主、Jakub 辅、Jhey 仅低频场景。本切片的空状态本身保持静态，避免无业务目的的入场动画。

## 3. 实施范围

新增 `ErpEmptyState.vue`：

- 必填标题与说明；
- 可选眉题、图形和操作插槽；
- 默认与紧凑两种密度；
- 使用语义化标题、`role=status` 与 `aria-labelledby`；
- 只使用项目设计令牌和静态 CSS，不依赖外部素材或新运行库。

工作台接入：

- 优先任务为空时显示“当前没有需要处理的优先任务”；
- 调拨阶段为空时显示“当前没有调拨阶段数据”；
- 非空列表保持原行为，不改变 Gateway、权限、路由或 Mock 数据。

同步校正 `docs/ERP-NEW_2-前端设计参考与使用约束.md` 的 2026-08-03 官方页面快照。

## 4. 验证

- 组件测试覆盖语义标题、说明、图形与操作插槽；
- 工作台测试覆盖非空业务数据和两个空队列；
- 执行格式、lint、TypeScript、Vitest、OpenAPI 静态门禁和生产构建；
- 不安装或升级依赖，不启动开发服务器，不执行 E2E 浏览器或网络请求。

## 5. 停止线

- 不复制或安装外部站点组件、提示词、素材、CLI 或依赖；
- 不引入 React、Next.js、Tailwind、shadcn/ui 或 Motion；
- 不连接后端、数据库、Redis、Nacos 或任何共享服务；
- 不修改旧 `erp-ui/`，不删除旧前端；
- 不启动 Docker 或服务，不修改端口与环境秘密；
- 不合并、不推送、不操作其他 worktree。
