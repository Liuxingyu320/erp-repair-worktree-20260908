# ERP-NEW_2 阶段 13P14：退回发货专属原子隔离收货骨架实施计划

> 日期：2026-08-03
>
> 分支：`codex/erp-new-2-rebuild`
>
> 基线：`094823e8 feat: guard adjudication return receipt planning`
>
> 范围：在生产零调用、双条件默认关闭的前提下，建立 `FIXED_RETURN` 发货专属原子隔离收货参与者

## 1. 目标与事实结论

P13 已证明 `FIXED_RETURN` 不能进入普通 V2 收货：普通路径会把残损再次创建为差异，且只用合格数量推进发货明细和调拨明细履约。P14 必须建立专属命令语义：

- 预期退回实收是已裁决残损的正常履约，不是新的残损差异；
- 预期退回实收必须进入目标仓 `quarantine` 库位、`damaged` 派生批次和隔离库存；
- 只有本次确认的意外短缺创建新的 `shortage` 差异事项；
- 发货明细和调拨明细累计实收按预期退回实收数量推进，而不是按普通合格数量推进；
- 多次部分收货、序列号、库存成本、计划漂移和生命周期必须继续满足原子守恒。

现有收货表和库存写模型已能表达上述事实：退回实收兼容存放在 `damaged_quantity`，意外短缺存放在 `shortage_quantity`，目标库存使用既有隔离数量和 `damaged` 派生批次。因此 P14 不新增 DDL，不执行迁移。

## 2. 写模型复用与语义隔离

继续由 `InvTransferShipmentReceiptMutationExecutor` 作为唯一收货 DML 执行者，避免出现第二套库存写顺序。对既有完整写意图增加显式语义：

- `ORDINARY`：保持现有合格/残损/短缺行为；
- `FIXED_RETURN`：合格数量必须为零，`damagedQuantity` 表示预期退回实收，差异维度只允许 `shortage`。

将明细累计写意图从容易误导的 `acceptedDelta` 更名为 `fulfillmentDelta`。普通收货仍传入合格数量，专属退回收货传入预期退回实收数量；Mapper 条件更新仍验证旧值、增量、结果值和已发/已配送上限。

Executor 在首条 DML 前验证：

- `FIXED_RETURN` 没有合格处置、可用库存或 `accepted` 台账；
- 每个预期退回实收都有 `damaged` 隔离库存、序列号和台账写意图；
- 只有短缺存在差异事项，预期退回实收不得生成 `damaged` 差异；
- 履约明细维度精确等于本次预期退回实收大于零的分配；
- 收货合计、进度、库存、成本、生命周期和目标主键关系完整。

## 3. 专属请求、锁定与纯策略

新增浏览器请求只允许：

- P13 专属计划版本和固定依据；
- 到货时间、是否完成本批、备注；
- 每个来源分配的隔离库位、预期退回实收数量、意外短缺数量；
- 序列号分别归入退回实收或短缺；
- 仅短缺要求说明和附件引用。

新增纯请求策略基于 P13 `Plan` 校验请求，生成专属不可变命令和 SHA-256 请求指纹。它不得接受合格分类、普通存储库位、规划外分配或规划外序列号。

扩展现有固定锁序 Gateway：

1. 发货批次与子调拨；
2. 调拨明细、发货明细和来源分配；
3. 目标仓库存模式和物料策略；
4. 目标汇总库存；
5. 来源批次和来源库位；
6. 目标 `damaged` 派生批次与隔离余额；
7. 未收序列号；
8. 锁后重读 P13 权威规划并重算计划版本。

普通路径仍重算普通规划并被 `FIXED_RETURN` 阻断；专属路径额外携带 P13 计划，不能借用普通请求策略绕过。

## 4. 原子收货参与者

新增 `Propagation.MANDATORY`、生产零调用的专属 Service。首条 DML 前必须完成：

- 独立双条件写开关验证；
- 根请求 ID、请求结构、登录用户和组织权限验证；
- 固定锁序及 P13 计划版本重算；
- 专属请求纯策略验证；
- 完整 Mutation 预演及 Executor 关系验证。

通过后在同一未来根事务内复用既有 DML 顺序：收货主单、目标隔离库存/批次/余额、汇总流水、收货分配、仅短缺差异、序列号、来源分配进度、履约明细、明细台账、发货/子调拨生命周期及状态日志。任何条件写影响行数异常均抛错并由外层事务回滚。

新增独立写 Gate，`write-enabled` 与 `lifecycle-boundary-ready` 均默认 `false`；仓库资源配置不得出现启用值。

- 纯策略覆盖整批、分批、批次、序列号、短缺、完成标记、计划漂移和规划外事实；
