## 2. 权限、组织与命令边界

| 动作 | 精确权限 | 组织限制 |
| --- | --- | --- |
| 查看树 | `inv:category:list` | 门店或仓库 |
| 新增 | `inv:category:add` | 门店或仓库 |
| 编辑 | `inv:category:query`、`inv:category:edit` | 门店或仓库 |
| 删除 | `inv:category:remove` | 门店或仓库 |

- 路由同时要求 `inventory.category.view` 与 `inv:category:list`；feature 由后端显式允许列表按该权限发布；
- 公司层级、缺失组织或缺失权限时不读取分类，动作按钮不渲染；保存和删除执行瞬间再次核对权限及组织；
- 请求只发送当前 `Dept-NumId`；读取省略 CSRF，写请求强制 CSRF、`X-Request-Id` 和同值 `Idempotency-Key`；
- 未修改表单的人工重试复用请求 ID，字段变化后生成新 ID；写操作不自动重试；
- 前端只提交名称、排序、状态、备注及必要的父级/分类 ID，不提交组织归属、祖先链、分类编码、删除标记或审计字段；
- Java `Long` 标识以十进制字符串保存并限制在正数范围内；递归树限制为 8 层、500 个节点并拒绝重复 ID、循环引用和父子嵌套不一致；
- 所有成功响应必须声明 `Cache-Control: no-store`，否则真实 HTTP Gateway 失败关闭。

## 3. 后端加固

- `InvProductCategoryController` 的树、详情、新增、更新和删除响应统一设置 `Cache-Control: no-store, max-age=0` 与 `Pragma: no-cache`；
- `InvProductCategoryServiceImpl` 拒绝负排序、负父级、非法状态和停用父级下新增，新增排序缺省为 0；
- 编辑继续丢弃客户端父级和祖先链，避免通过普通编辑迁移树结构；
- 删除继续由服务端权威阻断存在子分类或商品引用的分类；
- `InvProductCategoryMapper.xml` 在更新时持久化普通 `remark`；
- 既有相关组织数据范围、服务端分类编码生成、缓存清理和 `@IdempotentSubmit` 边界保持不变。

## 4. 界面与动效决策

高频 ERP 工作台采用 Emil Kowalski 为主、Jakub Krehel 为辅：

- 吸收 21st.dev、React Bits、UI Prompt Library、Magic UI、Motion Primitives、Uiverse 与 MotionSites 的信息层级和局部交互思路，不复制外部代码、品牌或资产；
- 树展开、筛选、键盘操作和刷新即时完成，不使用页面入场序列、循环光效、弹跳、视差或布局动画；
- 仅按钮和链接提供 140ms、可中断的按压/阴影反馈；
- `prefers-reduced-motion: reduce` 下关闭非必要过渡；加载、成功、失败和删除约束均有非动效语义文本；
- 编辑对话框支持初始焦点、Tab 焦点循环和 Escape 关闭，桌面与窄屏使用同一命令契约。
