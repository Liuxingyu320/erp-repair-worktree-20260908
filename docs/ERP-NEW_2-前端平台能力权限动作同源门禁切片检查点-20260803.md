## 1. 本检查点结果

已建立失败关闭的 capability 权威判定，解决调拨工作台动作链接与路由守卫分别判定的问题：

- 会话状态、会话快照、功能目录和所有必需权限由同一纯函数校验；
- 拒绝结果区分 `session-unavailable`、`feature-unavailable` 和 `permission-missing`；
- 未知功能和目录中已停用功能即使被伪造到会话中也会被拒绝；
- 多权限要求必须全部满足，不存在“命中一项即授权”的降级；
- 现有路由守卫改为委托同一 capability 判定，并保持会话问题与权限问题的既有跳转语义；
- 新增 `ErpCapabilityAction`，只在 feature 和全部 permissions 同时满足时渲染真实链接；
- 组件默认隐藏拒绝动作，也支持显式禁用模式与可读屏拒绝原因。

## 2. 调拨工作台接入

调拨工作台现在共有 7 个受权动作声明：

- 页头“新建调拨”使用 `inventory.transfer.create` + `inventory:transfer:create`；
- 桌面表格“版本”使用 `inventory.transfer.view` + `inventory:transfer:list`；
- 桌面表格“发货规划”使用 `inventory.transfer.ship` + `inventory:transfer:deliver`；
- 桌面表格“收货”使用 `inventory.transfer.receive` + `inventory:transfer:receive`；
- 移动调拨卡片补齐了同样的版本、发货和收货受权动作。

工作台中不再存在未经 capability 判定的原始 `RouterLink`。只读会话仍能使用版本历史，但不会看到新建、发货或收货入口。

## 3. 交互与无障碍

该动作用于高频 ERP 工作台，动效采用 Emil 为主、Jakub 为辅的克制决策：

- 授权结果变化时即时渲染，没有入场、离场、淡化、脉冲、弹跳、keyframes 或 transition；
- 按压只有无过渡的 `scale(0.98)` 即时反馈，`prefers-reduced-motion` 下显式移除；
- 默认隐藏模式不创建可聚焦的伪动作；
- 显式禁用模式使用真实 disabled button，其可访问名同时说明动作和拒绝原因；
- 移动端动作最小高度提升到 44px。
