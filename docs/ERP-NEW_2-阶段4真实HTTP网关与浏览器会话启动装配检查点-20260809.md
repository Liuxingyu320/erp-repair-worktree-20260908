## 1. 本检查点结论

新前端的非 Mock 启动不再直接落入全量 unavailable Gateway。当前实现先通过 ERP-NEW_2 专属 HttpOnly Cookie 恢复浏览器会话，再并行读取当前用户授权事实和授权组织树；三份事实全部通过严格契约、`no-store`、功能目录、稳定 ID 和默认组织一致性校验后，才会原子安装已有的真实 HTTP 适配器并把会话标记为 `ready`。

没有冻结真实契约、仍以 `simulate*` 命名或功能目录明确关闭的能力继续失败关闭。本检查点没有启动任何运行服务，因此结论只覆盖代码、单元/组件测试、生产构建与静态隔离门禁，不宣称已完成浏览器到后端的运行时联调。

## 2. 浏览器会话与认证边界

- 新增专属 Cookie `ERP_NEW_2_BROWSER_SESSION`；登录只通过 `Set-Cookie` 传输访问令牌，响应 JSON 仅返回会话绑定的 CSRF 证明与有效期。
- Cookie 默认使用 `HttpOnly`、`Secure`、`SameSite=Strict` 和 `Path=/`；退出清除同名、同路径 Cookie，并使服务端登录态失效。
- CSRF 证明使用 HMAC-SHA256、固定域分隔符、会话访问令牌和独立的 ERP-NEW_2 密钥生成；比较采用常量时间算法。
- 独立密钥必须不少于 32 字节，空值、纯空白、短值和缺失配置全部失败关闭。仓库根 `.env.example` 故意保留空密钥，直接启用时不会把公开占位符误当成有效秘密。
- 浏览器会话功能默认关闭；认证服务与网关都只读取 `ERP_NEW_2_BROWSER_SESSION_*` 变量，不读取或复用原项目 `.env`、JWT、数据库、Redis 或 Nacos 密钥。
- 保留原有 Bearer Token 客户端兼容路径；浏览器 Cookie 模式不会把访问令牌暴露给前端 JavaScript。

## 3. 网关安全行为

- Bearer 头优先，现有 API 客户端无需 CSRF；只有显式启用且密钥有效时才读取 ERP-NEW_2 专属 Cookie。
- Cookie 模式的 GET、HEAD、OPTIONS 可在会话有效时通过；POST、PUT、PATCH、DELETE 必须携带与当前会话绑定的 `X-CSRF-Token`。
- 缺失或篡改 CSRF 返回真实 HTTP 403；缺失、无效或过期会话返回真实 HTTP 401，不再以 HTTP 200 包装鉴权错误。
- 网关在完成 JWT 与 Redis 登录态校验后才向下游注入 Bearer 和用户身份头；外部伪造的用户 ID、用户名和用户键会被覆盖，不会追加为第二个可信值。
- `/auth/browser/login` 同时加入登录白名单与验证码过滤范围；`/auth/browser/session` 读取和删除端点仍必须经过网关鉴权，删除操作还必须通过 CSRF。
- 鉴权失败响应强制 `Cache-Control: no-store`，日志不记录 Cookie、访问令牌或 CSRF 值。

## 4. 授权会话事实

- `/system/user/getInfo` 新增 `frontendPermissions` 和 `frontendFeatures`；服务端只从显式允许列表发布前端已知功能。
- 功能目录按完整后端权限和业务开关计算；未知功能及差异裁决隔离原型不会被发布，目录依赖缺失时返回空集合。
- `/system/user/getInfo` 与 `/system/dept/shop-tree` 的成功响应均强制 `no-store`；组织树仍由现有服务端数据范围产生。
- 前端只接受正 Long 范围内的用户/组织 ID、无重复的角色/权限/功能、已知功能代码和启用组织。默认组织不在授权树、响应可缓存或契约漂移时，整个会话失败关闭。
- HTTP 401 会把会话标记为过期；其他网络、配置或契约错误标记为不可用。任何失败都保留全量 unavailable Gateway，不产生部分真实接线。

## 6. 代码审查修复

提交前高风险自审没有遗留 P0/P1 发现，并完成以下修正：

- 长占位密钥会意外通过最小长度校验：示例值改为空，误启用必然失败关闭。
- 纯空白密钥和带空白的 CSRF 证明：分别拒绝并补充负向测试。
- 外部身份头可能与网关注入值并存：统一改为覆盖写入并验证只有一个可信值。
- 会话 ID 字符串缺少 Long 上界：与后端 Long 契约对齐并补充越界测试。
- 多个并发 401 可能重复广播失效：启动器只在尚未过期时触发一次会话失效。
- 真实 HTTP 模式仍显示全局 Mock 标签：改为按运行配置显示真实模式，并清理已接线页面的误导性 Mock 文案。
