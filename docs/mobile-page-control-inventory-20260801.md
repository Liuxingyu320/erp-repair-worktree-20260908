# ERP 手机端页面与控件全量台账（2026-08-01）

## 结论

源码层面的全量页面与控件清单已整理完成，作为后续视觉改造和验收基线。当前台账覆盖：

- 58 个唯一手机业务路由；
- 8 个公共入口/状态页：登录、注册、强制改密、资料补全、选择店铺/仓库、401、404、锁定屏幕；
- 20 种路由页面实现，37 个手机端 Vue 页面/共享组件；
- 38 个复用通用业务模板的页面，并已按路由动作和权限拆分；
- 静态模板识别到 302 个按钮、137 个输入/选择字段、9 个选择/切换控件声明、5 个上传入口、36 个弹窗/抽屉、16 个导航/搜索/标签区域、101 个加载/空态/错误/状态反馈区域；
- 另有 16 个非语义点击节点，列为可访问性整改项。

数字是源码静态盘点值：同一共享组件只计一次；实际运行时还要按角色权限、组织类型和接口数据验收显示/隐藏状态。

## 关键流程验收清单

### 云盘验收

页面目前已有空间选择、根目录、搜索、上传、回收站、预览、下载、移动、重命名、删除/恢复、重试和容量/写入阻断状态。下一轮视觉改造必须补齐“待验收/已验收/退回/审核人/验收记录”可见层级，并确保列表、详情、预览和操作抽屉使用同一状态颜色和按钮语义。

### 报销发票

页面目前已有拍照发票、批量选择、自动识别、标题/事由、费用明细增删、金额、发票预览/下载、草稿、提交、撤回和审核/财务路径。下一轮必须把“识别中、识别成功、识别异常、待补充、已提交、审核中、已通过、已驳回、已付款”做成统一状态组件，并在移动端保持主操作固定可见。

### 签约与人事

签约包含四类状态、合同翻页/缩放/阅读确认、签署/拒签/重试；人事入职包含四步表单、资料缺失、负责人选择、合同/社保资料。两条流程需要统一步骤指示、底部操作栏、异常恢复和权限提示。
