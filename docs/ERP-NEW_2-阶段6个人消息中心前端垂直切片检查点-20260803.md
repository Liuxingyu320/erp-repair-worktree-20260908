## 2. 明确业务边界

- 本切片只重建旧 `system/userNotification` 的“我的消息”，不把 `system/notice` 系统公告合并进来。
- 旧消息数据由后端按当前登录用户限定，不是组织范围资源；真实 HTTP 读取和已读写入均显式省略组织头。
- `GET /system/user-notification/list` 不发送 CSRF；`POST /system/user-notification/{id}/read` 必须发送 CSRF。
- 真实 HTTP 适配器已经具备契约测试，但仍未注入默认运行时；默认只使用隔离 Mock，不连接任何后端或共享服务。
- 旧 OA 等尚未迁移的目标路由不会被盲目打开，而是显示“关联功能迁移中”。
- 后端分页、批量已读、强写回执、真实消息深链和系统公告独立迁移仍待后续确认与实现。
