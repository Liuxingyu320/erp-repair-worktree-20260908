# 移动端页面功能清单

> 基线日期：2026-07-29
> 当前端形态：同一 Vue 前端中的移动路由，同时用于移动浏览器和 Capacitor 原生壳。
> 审计结果：源码共定义 59 个固定移动路由；既有审计记录显示 59/59 可访问且未出现白屏，但未完成全部写操作、角色组合、弱网和生产原生包验收。

## 1. 移动端产品定位

移动端不复制 PC 大表格和后台配置，主要承担：

- 看：本人、团队、当前组织和当前任务的关键信息；
- 审：查看业务上下文后同意、退回、驳回、转交；
- 执：打卡、收货、质检、出库、收货确认、盘点；
- 录：少字段快速录入、分步入职、草稿续填；
- 采：扫码、拍照、上传附件、现场取证；
- 响应：消息提醒、异常处理、超期事项；
- 查：商品、库存、员工、合同、业务单详情。

复杂配置、批量导入、跨组织分析、清空日志和流程设计应以 PC 为主。

## 2. 目标一级结构

移动端统一为五个固定一级入口：

```text
工作台
├─ 今日待办摘要
├─ 风险/异常
├─ 当前组织
├─ 最近业务
└─ 角色化快捷入口

消息
├─ 系统通知
├─ 审批提醒
├─ 任务提醒
└─ 业务消息

待办
├─ 待审批
├─ 待执行
├─ 被退回
├─ 风险提醒
└─ 个人事项

应用
├─ 人事
├─ OA
├─ 门店
├─ 仓储
├─ 库存
└─ 合同与文件

我的
├─ 个人资料
├─ 当前组织/切换组织
├─ 我的合同/薪资/考勤
├─ 设置与帮助
└─ 退出登录
```

“首页”即“工作台”。无论用户是门店、仓库、HR 还是管理员，底部一级结构保持不变，只改变卡片和应用权限。

## 4. 核心移动页面详细设计

### 4.1 工作台

**页面定位**
用户打开应用后 10 秒内知道“今天需要处理什么、哪里有风险、下一步点哪里”。

**页面功能**

- 当前组织：名称、类型、切换入口；
- 今日待办：待审批、待执行、被退回、风险提醒、个人事项；
- 关键异常：库存不足、调拨差异、合同/健康证到期、资料缺失；
- 快捷入口：由角色、组织和最近使用共同决定，最多 8 个；
- 最近业务：最近处理的 3—5 条单据；
- 数据状态：更新时间、部分来源失败提示和重试。

**操作流程**

```text
打开应用
→ 恢复有效会话和上次组织
→ 并行加载待办摘要、风险摘要、快捷入口
→ 10 秒内显示可操作内容
→ 点击卡片
→ 进入待办筛选结果或业务详情
→ 完成处理
→ 返回后摘要刷新
```

**权限**

- 卡片由服务端返回或按服务端权限结果过滤；
- 无某业务权限时不显示其快捷入口；
- 组织切换仅展示被授权组织；
- 某来源失败时显示“暂不可用”，不能显示假 0。

### 4.2 消息

**页面定位**
告诉用户“发生了什么”，不承担尚未完成的任务清单。

**消息分类**

- 系统通知：版本、维护、安全通知；
- 审批提醒：提交成功、审批通过、退回、驳回；
- 任务提醒：待收货、待出库、资料待补、签署待办；
- 业务消息：库存异常、合同到期、健康证到期、调拨差异。

**操作流程**

```text
消息列表
→ 打开消息
→ 标记已读
→ 通过业务类型和业务 ID 打开移动详情
→ 当前端无处理能力时显示原因，并提供受控 PC 链接
→ 完成业务后返回消息
```

**权限**

- 只能读取发给本人或本人所属受众的消息；
- 深链打开时重新执行目标页面和数据权限校验；
- 删除或撤销业务权限后，旧消息不能成为越权入口。

### 4.3 待办

**页面定位**
统一所有“现在需要我行动”的事项。

**页面功能**

- 顶部分类：待审批、待执行、被退回、风险、个人；
- 筛选：组织、来源、优先级、截止时间；
- 卡片：业务标题、关键金额/数量、发起人、组织、等待时间、下一动作；
- 批量只读选择；移动端默认不批量审批；
- 来源失败提示、重试和最近一次成功更新时间。

**操作流程**

```text
选择分类
→ 查看按紧急度排序的事项
→ 打开详情
→ 查看业务字段、附件和完整审批轨迹
→ 同意/退回/执行/补资料
→ 服务端提交幂等请求
→ 成功后该事项退出当前列表
```

**权限**

- 必须同时满足业务权限、数据范围、当前任务所有权；
- 仅审批人本人或合法代理人可执行审批；
- 已被他人处理的任务返回“状态已变化”，刷新为最新状态。

### 4.4 应用

**页面定位**
提供低频但完整的移动业务入口，不把所有页面挤在工作台。

**信息架构**

| 分组 | 标准应用 |
|---|---|
| 人事 | 入职、员工、团队、完整度、健康证 |
| OA | OA 采购、考勤、资产报修 |
| 门店 | 销售、客户、退货、补货、库存 |
| 仓库 | 采购、采购退货、收货质检、出库、盘点、调拨 |
| 查询 | 商品、OE、赠品、供应商、库存流水 |
| 合同与文件 | 合同、我的签约、文件空间 |
| 管理员工具 | 仅经确认的只读安全/运行诊断入口 |

**权限**

- 无权限应用完全不显示；
- 有列表权限但无新增权限时仍可进入，但不显示新增按钮；
- 组织不匹配时显示“请切换到门店/仓库”，而不是空白页。

### 4.5 我的

**页面定位**
聚合本人资料、个人业务和应用设置。

**页面功能**

- 头像、姓名、岗位、组织；
- 切换组织；
- 我的合同、工资、考勤、健康证、签约；
- 个人资料和密码；
- 缓存/网络诊断、帮助、隐私说明；
- 退出登录。

**权限**

- 本人数据必须由服务端使用当前用户身份获取；
- 不能通过前端传入其他 userId 查看他人“我的”数据；
- 工资、身份证、银行卡等字段按场景脱敏。

## 5. 业务页面交互模板

### 5.1 列表页

- 顶部只保留关键字、状态和组织三个高频条件；
- 其他条件放入底部筛选抽屉；
- 卡片首屏展示单号/对象、状态、金额或数量、时间、责任人；
- 底部主按钮只显示当前状态允许的一个首要动作；
- 支持下拉刷新、滚动分页、空状态、失败重试；
- 返回列表时保留筛选和滚动位置。

### 5.2 详情页

- 顶部固定显示状态、单号、组织和风险；
- 按“摘要、明细、附件、审批/操作轨迹”折叠分组；
- 操作按钮固定底部，安全区适配；
- 危险动作必须二次确认并说明后果；
- 状态变化后原按钮立即失效，避免重复提交。

### 5.3 表单页

- 10 个以上字段采用分步表单；
- 每步只收集一个业务主题；
- 自动保存本地草稿，但服务端提交仍为唯一业务真相；
- 离开页面前提示未保存内容；
- 上传显示逐文件进度、失败原因和重试；
- 数量、金额、日期、组织、人员使用专用输入控件；
- 服务端字段错误定位到具体步骤和字段。

### 5.4 扫码执行页（目标新增）

```text
进入收货/出库/盘点任务
→ 请求相机权限
→ 扫描商品/批次/库位
→ 服务端校验任务范围
→ 显示商品和计划数量
→ 输入/确认实际数量
→ 连续扫描
→ 汇总差异
→ 提交
```

扫码只是输入方式，不改变采购、配送、盘点或调拨的服务端状态机。

## 7. 移动页面验收清单

### 功能与闭环

- [ ] 当前状态只显示允许的动作；
- [ ] 动作成功后列表、详情、待办、消息和 PC 状态同步；
- [ ] 退回、驳回、撤回、取消、差异和重开可继续处理；
- [ ] 无移动处理能力时明确说明，且该场景确实属于 PC 管理职责；
- [ ] 不存在为了补一个普通执行字段被迫返回 PC 的情况。

### 移动体验

- [ ] 390×844 和 320×568 均无横向滚动、遮挡或不可点击；
- [ ] 底部按钮避开 iPhone/Android 安全区；
- [ ] 键盘不遮挡当前字段和提交按钮；
- [ ] 单手主要操作位于屏幕下半区；
- [ ] 弱网、超时、断网、重复点击和上传失败均可恢复；
- [ ] 相机、相册、文件权限拒绝后有替代路径；
- [ ] 文字缩放、对比度、焦点和读屏标签可用。

### 权限与安全

- [ ] 每条移动深链重新校验功能权限、数据范围、组织和任务所有权；
- [ ] 切换组织后旧页面、缓存和待办立即失效或刷新；
- [ ] 本人数据接口不能接受可篡改的他人 ID；
- [ ] 高风险操作使用独立权限、二次确认和审计；
- [ ] 附件下载和预览使用短期授权，退出后不可继续访问。

## 8. 当前移动端验证缺口

1. 59 个路由可访问，不等于 59 个业务流程已闭环。
2. 需要至少使用普通员工、门店人员、仓库人员、部门经理、HR、有限管理员六类账号验收。
3. 采购、销售、退货、调拨、盘点、入职、健康证、OA 采购、资产报修、签署必须在隔离数据中执行写流程。
4. 必须补齐 HTTPS UAT 环境、推送/深链、相机上传和 iOS/Android 生产候选包真机测试。
5. 当前移动系统管理入口应在产品确认后收缩；在确认前不得简单删除路由，以免破坏既有用户路径。
