## 2. 权限、组织与路由边界

| 动作 | 路由/入口 | 精确权限 | 组织限制 |
| --- | --- | --- | --- |
| 新增 | `/inventory/products/new` | `inv:product:add`、`inv:category:tree`、`inv:supplier:list` | 仅仓库 |
| 编辑/停启用 | `/inventory/products/:productId/edit` | `inv:product:query`、`inv:product:edit`、`inv:category:tree`、`inv:supplier:list` | 仅仓库 |
| 删除 | 商品详情两步确认 | `inv:product:query`、`inv:product:remove` | 仅仓库 |

- 路由继续要求既有 `inventory.product.view` feature；页面组件在脱离路由单独挂载时再次检查权限与仓库上下文；
- 门店/公司上下文不加载分类或供应商选项，不发送写命令；
- HTTP Client 在发送前验证当前会话组织与命令组织一致，请求只发送一个 `Dept-NumId`；
- 商品 ID 仍使用后端 `Long` 范围内的十进制字符串；
- 仓库可读取及维护后端授权范围内的上级共享商品，所以读取和编辑响应的所属组织不强制等于当前仓库；新增结果必须属于当前仓库，所有数据范围仍由后端权威校验。

## 3. 命令与响应安全

### 3.1 精确接口

- `GET /inventory/supplier/list?pageNum=1&pageSize=1000&status=0&cooperationStatus=0`；
- `POST /inventory/product`；
- `POST /inventory/product/update`；
- `DELETE /inventory/product/{productId}`。

所有成功响应都必须声明 `no-store`。写请求必须携带 CSRF、当前组织头、同值且已校验的 `X-Request-Id` 与 `Idempotency-Key`；前端不自动重试写操作。

### 3.2 请求白名单

前端只重建并提交：

- 商品名称、分类 ID、等级、SKU、规格、尺寸、单位；
- 销售参考价、250g/500g 售价、安全库存上下限；
- 编辑时上述五个可选数值留空会通过只写 `clear*` 标记显式清空，未发送标记的旧客户端不受影响；
- 供应商名称、内部名称、商品描述、条码、普通备注和启停状态；
- 更新时的商品 ID。

商品编码、组织归属字段、采购价、成本价、供应商联系方式/采购备注、图片/附件、删除标记、审计字段和未知扩展字段均不会进入请求体。供应商响应只投影 ID、名称和编码。编辑契约保留原始空值，显示层才生成“未设置”文本，避免把占位内容写回数据库。

### 3.3 幂等与错误恢复

- 未修改表单的人工重试复用同一请求标识；
- 表单内容变化后生成新请求标识，避免同一幂等键复用不同载荷；
- 保存失败保留全部输入和错误信息；
- 删除需要先显示精确商品编码和名称，再由用户显式确认；
- 后端若发现库存或历史单据引用，继续拒绝删除并提示停用商品。

## 4. 后端加固

- 商品新增、更新和删除响应统一设置 `Cache-Control: no-store, max-age=0` 与 `Pragma: no-cache`；
- 无 `inv:cost:view` 时，控制器在调用服务前清空请求采购价/成本价，并在返回前再次脱敏；导入路径也不能绕过该边界；
- 商品服务拒绝负价格、负安全库存、库存上下限倒置及非 `0/1` 状态；部分更新会合并清空标记、新值和数据库原值后校验最终安全库存范围；
- 五个可选销售/库存数值使用只写清空标记与 Mapper `choose` 分支，支持显式写入 `null`，且不改变旧客户端省略字段时的行为；
- 商品更新 Mapper 补齐普通 `remark` 持久化；
- 供应商列表成功响应设置相同的禁止缓存头；
- 既有 `@IdempotentSubmit` 继续以 `Idempotency-Key`、用户、组织、方法和 URI 建立隔离键。

## 5. 界面与动效决策

高频企业 ERP 界面采用 Emil Kowalski 为主、Jakub Krehel 为辅：

- 表单按“基础信息 / 销售与库存参数 / 描述与备注”分组，桌面多列、窄屏单列；
- 吸收 21st.dev、React Bits、UI Prompt Library、Magic UI、Motion Primitives、Uiverse 与 MotionSites 的信息层级和局部交互思路，不复制其外部代码、品牌或资产；
- 不使用页面入场序列、循环光效、弹跳、视差、大幅缩放或布局动画；
- 仅链接和按钮提供 140–160ms、可中断的按压/阴影反馈；
- `prefers-reduced-motion: reduce` 下关闭非必要过渡；所有成功、失败、加载和删除结果均有非动效文本与语义状态。
